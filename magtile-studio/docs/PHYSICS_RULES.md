# 物理校验规则 (Physics Rules)

本文档精确定义 MagTile Studio 对模型与教程步骤执行的物理校验规则。实现位于 `src/physics/physics_validator.cpp`, 参数集中在 `PhysicsConfig`。

## 0. 校验范围与目标

物理校验的目标不是精确的刚体仿真, 而是回答一个商业问题: **用户照着教程搭, 每一步都能搭得起来、放得稳吗?**

规则分两组:

- **几何/拓扑规则 R1~R4**: 结构是否连通、贴合、不穿插、不倾倒;
- **静力学/工艺规则 R5~R8**: 每条磁力连接是否真的撑得住 (磁吸边是铰链不是刚性节点), 以及每一片按教程顺序放置时是否放得进去。

校验器对以下对象逐一执行全部静态规则 (R1~R6、R8):

1. 最终成品 (`final_assembly` 全集);
2. **每一个教程步骤完成后的中间状态** (第 1 步完成后、第 2 步完成后、……)。

R7 (装配可达) 则按教程步骤与步骤内 `tiles_to_add` 的先后顺序**逐片**模拟放置。

任何一条 Error 级问题都会使模型质检失败 (`magtile_app validate` 返回非零), 不允许进入发布内容库。Warning 不阻断发布, 但须逐条评审 (见 `BUILD_VERIFICATION.md` 第 5 节)。

## 1. 术语与参数

长度单位与世界坐标一致 (1.0 = 正方形边长, 实物约 70mm); 质量单位为克, 按面积折算。

### 1.1 几何容差 (R1~R4)

| 参数 (PhysicsConfig) | 默认值 | 含义 |
| --- | --- | --- |
| `connect_tolerance` | 0.02 | 磁力边端点吸合容差 (0.02 单位 ≈ 1.4mm 实物) |
| `ground_tolerance` | 0.02 | 顶点视为"接触地面"的最大高度 |
| `overlap_tolerance` | 0.02 | 判定重叠所需的最小穿插深度 (排除共享边的相邻片) |
| `coplanar_tolerance` | 0.02 | 共面判定: 两平面间距上限 |
| `stability_margin` | 0.15 | 重心水平投影允许超出接地凸包的距离 (磁吸提供的裕量) |

### 1.2 静力学参数 (R5/R6)

| 参数 | 默认值 | 含义与取值依据 |
| --- | --- | --- |
| `tile_mass_per_area` | 30.0 | 面密度 g/单位面积 (正方形 1×1 实测约 30g) |
| `hanging_capacity_per_edge` | 150.0 | 单位长度磁力边的额定悬挂承重 (克)。实测一条标准边竖直悬挂约在 5 片正方形 (150g) 时脱落 |
| `hinge_moment_capacity_per_edge` | 25.0 | 单位长度磁力边的额定抗弯矩 (g·单位)。实测单片正方形平挑墙顶 (力矩 30g×0.5=15) 勉强稳住, 两片连挑 (力矩 60) 必掉, 取 25 |
| `knock_safety_factor` | 0.8 | 抗震/碰撞安全系数: 只允许用到额定承载的 80%, 保留 20% 抗碰撞裕量 |
| `max_hanging_tiles_per_edge` | 4 | 单条铰链边悬挂链片数上限, 超出仅 Warning (逐级铰链累积晃动) |
| `hanging_z_tolerance` | 0.1 | 悬挂判定: 子结构重心须低于铰链线至少此距离才算"受拉" |
| `collinear_tolerance` | 0.02 | 磁力边共线分组容差 (共线边合成一条铰链线) |

### 1.3 结构冗余参数 (R8)

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `tall_structure_height` | 2.5 | 最高点达到此高度即视为高层结构, 启用 R8 |
| `spof_min_component_tiles` | 3 | 单点失效警告阈值: 单条连接独自支撑的最少片数 |

- **磁力边**: 形状目录中 `magnet_edges` 列出的边 (例如扇形的弧边不是磁力边)。
- **接地片**: 存在顶点满足 `z ≤ ground_tolerance` 的磁力片。
- **铰链线**: 位于同一条空间直线上的一组磁力连接。磁吸边连接在实物上是"铰链": 抗压强 (下方有支撑时稳), 抗拉与抗弯都弱, R5/R6 正是对这两个弱项做预算校验。

## 2. 几何/拓扑规则 (R1~R4)

### R1 接地支撑 (floating_tile)

> 每片磁力片必须存在一条经由磁力连接到达地面的支撑路径; 只有接地层磁力片可以直接接触地面。

判定: 以全部接地片为起点, 在磁力连接图 (见 R2) 上做广度优先搜索; 任何不可达的磁力片报 Error `floating_tile` ("悬空")。

这是"禁止悬空"的图论化表述: 允许力沿磁吸边传递 (立墙上再立墙、墙顶挂城齿都合法), 但空中孤片、只靠"视觉贴近"而没有磁力边贴合的片都会被判悬空。

### R2 磁力连接 (isolated_tile / disconnected_assembly)

> 相邻磁力片必须通过**等长磁力边完全贴合**吸附。

判定: 两条磁力边视为吸合, 当且仅当端点两两重合 (正序或反序), 距离容差 `connect_tolerance`。由此得到磁力连接图:

- 多片模型中存在零连接的磁力片 → Error `isolated_tile`;
- 连接图不连通但各部分均接地 → Warning `disconnected_assembly` (物理上成立, 但要求内容制作者在教程中明确分组说明)。

端点两两重合意味着两条边**等长且完全对齐**——这正是磁力片的真实吸附方式: 只有整边贴合时磁条才对齐, 半搭 (错位半格) 在实物上是不稳定的, 直接判为未连接。

### R3 无重叠 (tile_overlap)

> 任意两片磁力片不得互相穿插。

判定: 仅对**共面**的片 (法向平行且平面间距 ≤ `coplanar_tolerance`) 执行, 将两多边形投影到公共平面后做**分离轴检测 (SAT)**: 所有候选轴上的重叠深度都超过 `overlap_tolerance` 才判为重叠 → Error `tile_overlap`。

共享一条边的相邻片在该边法向轴上的重叠深度为 0, 因而不会误报; 不共面的片 (如地台与立墙) 天然不参与本规则。

第一阶段的形状全部是平面凸多边形, 共面 SAT 已覆盖实际穿模场景 (同层重铺、立墙插入地台等); 非共面斜穿的情形留待规则演进 (见第 6 节)。

### R4 重心稳定 (unstable_center_of_mass / no_ground_contact)

> 整体重心的水平投影必须落在接地区域内 (基础版)。

判定 (磁力片厚度、密度一致, 重量 ∝ 面积):

1. 重心 `COM = Σ(质心ᵢ · 面积ᵢ) / Σ面积ᵢ`;
2. 接地区域 = 全部满足 `z ≤ ground_tolerance` 的顶点在水平面上的**凸包** (Andrew 单调链);
3. `COM` 的水平投影到凸包的带符号距离 > `stability_margin` → Error `unstable_center_of_mass`;
4. 不存在任何接地顶点 → Error `no_ground_contact`。

`stability_margin` 表达磁吸提供的抗倾覆裕量: 单面立墙的接地区域退化为一条线段, 理想刚体下重心恰在线上属于临界平衡, 但实物磁力片靠底边磁吸完全立得住, 因此允许 0.15 单位的超出量。悬臂式外挑结构 (重心明显越过支撑边) 由 R4 与 R6 双重把守。

## 3. 静力学/工艺规则 (R5~R8)

R1~R4 只回答"结构是否连通且不倾倒", 却把每条磁力连接当成无限强——这正是"校验通过但实搭时掉下来"的根源。R5/R6 用**铰链切割静力分析**补上这一课。

**分析方法** (R5/R6 共用): 把所有共线的磁力连接归并为一条**铰链线**, 逐条假想剪断; 剪断后与地面失联的每个子结构, 其全部重量必须经由这条铰链传递:

- 子结构重心低于铰链线 (差距 > `hanging_z_tolerance`) ⇒ **悬挂**, 磁条受拉, 校验 R5 承重预算;
- 重力绕铰链轴产生的力矩 ⇒ **悬臂**, 磁条受弯, 校验 R6 力矩预算。

被三角斜撑 / 环状结构加固的部分, 剪断单条铰链线后仍有其他支撑路径, 自然不会成为失联子结构——**桁架的加固效果由图论连通性隐式表达**, 无需显式豁免规则。

前置条件: R1 通过且存在接地片 (悬空结构做静力分析没有意义)。

### R5 悬挂承重 (hanging_chain_overload / hanging_chain_long)

> 经由单条铰链线悬挂的磁力片总重, 不得超过该铰链线的承重预算。

判定 (对每条铰链线、每个剪断后失联且重心低于铰链线的子结构):

1. 子结构质量 = Σ(面积ᵢ × `tile_mass_per_area`);
2. 承重预算 = `hanging_capacity_per_edge` × 跨越铰链线的磁力边总长 × `knock_safety_factor` (默认 150 × 长度 × 0.8 = 120g/单位边长, **约合每条标准边 4 片正方形**);
3. 质量 > 预算 → Error `hanging_chain_overload` ("实搭时整串会脱落");
4. 质量未超, 但子结构片数 > `max_hanging_tiles_per_edge` × 跨越边数 → Warning `hanging_chain_long`: 铰链节点逐级累积晃动, 轻碰易整串脱落, 建议单边悬挂不超过 4 片。

### R6 悬臂力矩 (cantilever_overload)

> 单边连接是铰链而非刚性节点, 悬挑结构绕铰链轴的重力力矩不得超过抗弯预算。三角斜撑 / 外挑远端加支撑可豁免 (通过增加支撑路径自然豁免)。

判定 (对每条铰链线、每个剪断后失联的子结构):

1. 力矩 = |Σ mᵢ · ((质心ᵢ − 铰链点) × ĝ) · 铰链方向|, 即重力绕铰链轴的合力矩。正上/正下方的子结构力矩为零 (纯压/纯拉), 水平外挑越远力矩越大;
2. 抗弯预算 = `hinge_moment_capacity_per_edge` × 铰链线上磁力边总长 × `knock_safety_factor` (默认 25 × 长度 × 0.8 = 20 g·单位/单位边长);
3. 力矩 > 预算 → Error `cantilever_overload`, 提示"请添加三角斜撑或在外挑远端增加支撑"。

标定示例 (正方形 30g): 单片平挑墙顶力矩 = 30 × 0.5 = 15 < 20 → 放行 (实物确实勉强稳住); 两片连挑力矩 = 30×0.5 + 30×1.5 = 60 > 20 → 拒绝 (实物必掉)。

### R7 装配可达 (unplaceable_tile / enclosed_placement)

> 按教程顺序逐片放置时, 每片在放下的那一刻必须有依托, 且放置点必须从外部伸手可达。

静态规则保证每个中间状态"放好之后是稳的", R7 回答"这一片当时放得进去吗"。按教程步骤与步骤内 `tiles_to_add` 列表顺序逐片模拟, 与真人搭建顺序完全一致:

- **R7a 放下瞬间必须有依托**: 既不接地 (`ground_tolerance`)、又吸不到任何已放置磁力片 (`connect_tolerance`) → Error `unplaceable_tile`, 松手即掉。常见于步骤内 `tiles_to_add` 顺序写反 (先列了上层片)。
- **R7b 放置点必须从外部可达**: 从新片质心向正上、水平四向、水平对角四向、斜上四向共 **13 个方向**发射射线, 全部被已放置磁力片挡住 → Error `enclosed_placement` (封闭腔体内部, 手和磁力片都伸不进去)。不检测正下方 (桌面本来就挡)。常见于"先封顶再补内部隔断"的教程。

### R8 结构冗余 (single_point_of_failure / no_structural_redundancy)

> 高层结构 (最高点 ≥ `tall_structure_height`) 中, 警告单点失效连接与纯树状拓扑。Warning 级, 不阻断发布。

结构越高, 碰撞与桌面震动的放大效应越强; "被小朋友撞一下"无法静态精确建模, 因此只做拓扑级提示:

1. **单点失效**: 逐条剪断单条磁力连接, 若失联片数 ≥ `spof_min_component_tiles` → Warning `single_point_of_failure`: 掉一处塌一片, 建议增加三角桁架或第二条连接路径;
2. **无环拓扑**: 环路数 = E − (V − 连通分量数) 为零, 说明连接图纯树状, 没有任何三角桁架/闭合环, 每个节点都是自由铰链 → Warning `no_structural_redundancy`, 整体会像风铃一样晃。

R8 警告的点位是实物验证 (`BUILD_VERIFICATION.md` 3.6.4) 中"误碰即塌"问题的第一修复参考。

## 4. 报告格式

每条问题包含: 严重级别 (Error / Warning)、稳定的机器可读 `code`、中文 `message` (含上下文前缀, 如"第 5 步完成后")、涉及的磁力片 `id` 列表。code 全集:

| code | 级别 | 规则 |
| --- | --- | --- |
| `floating_tile` | Error | R1 |
| `isolated_tile` | Error | R2 |
| `disconnected_assembly` | Warning | R2 |
| `tile_overlap` | Error | R3 |
| `unstable_center_of_mass` / `no_ground_contact` | Error | R4 |
| `hanging_chain_overload` | Error | R5 |
| `hanging_chain_long` | Warning | R5 |
| `cantilever_overload` | Error | R6 |
| `unplaceable_tile` / `enclosed_placement` | Error | R7 |
| `single_point_of_failure` / `no_structural_redundancy` | Warning | R8 |

CLI 示例:

```
[错误] 第 5 步完成后: 磁力片 w2_s_1 悬空: 不存在通往地面的支撑路径 (floating_tile)
[警告] 最终成品: 高层结构单点失效: t1_a 与 t1_b 之间的单条磁力连接是 3 片子结构的唯一支撑路径 (single_point_of_failure)
```

## 5. 参数标定与调参纪律

R5/R6 的预算参数来自实物测量 (见 1.2 节表格中的取值依据), 并统一乘 `knock_safety_factor = 0.8` 保留抗碰撞裕量。调参必须遵守:

1. **宁严勿松**: 真实能搭成的模型必须放行, 明显会掉的结构必须拒绝; 两者冲突时优先保证后者, 通过修改模型 (加固) 而不是放宽参数来解决前者;
2. 任何参数改动后, `tests/test_physics_negative/` 负例套件必须仍然全部被拒绝, `tests/test_physics_positive/` 正例夹具与全库模型必须仍然通过 (`tests/test_all_models.sh`);
3. 实物验证 (见 `BUILD_VERIFICATION.md`) 中"软件放行但实搭失败"的案例, 一律回填为负例夹具后再收紧参数——用回归用例锁住每一次教训。

## 6. 与教程一致性检查的分工

物理规则之外, `TutorialEngine::checkConsistency` 负责纯数据层面的质检 (步骤序号连续、每片恰好放置一次、引用存在、说明非空)。`magtile_app validate` 同时执行两类检查, 全部通过才判定"可发布"。

## 7. 规则演进路线

已在本版落地的前路线项: 逐片力矩分析 (→ R6)、搭建顺序人因校验的可达性部分 (→ R7)。后续按内容库需要演进:

1. **非共面穿插检测**: 多边形对的 3D 相交测试, 覆盖斜插穿模;
2. **子结构稳定性**: 对每个连通子结构独立做重心检查 (当前对整体做);
3. **单手可放置校验**: R7 只判"伸得进去", 未判"单手拿稳一片的操作空间", 需要手部包围体模型;
4. **柔性接头模拟**: 磁吸片受压时的微小转动, 用于球面/穹顶类高难模型的可搭性预判;
5. **刚体仿真层**: 蒙特卡洛容差抖动与扰动脉冲测试, 作为验证金字塔第 2 层 (见 `BUILD_VERIFICATION.md` 第 1 节), 捕捉静力预算近似不了的临界稳定问题。
