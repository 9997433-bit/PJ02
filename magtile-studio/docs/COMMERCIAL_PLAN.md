# MagTile Studio 商业化产品策略

本文档是 MagTile Studio 的商业化总纲, 与 [ROADMAP.md](ROADMAP.md) (工程阶段) 和 [CONTENT_STRATEGY.md](CONTENT_STRATEGY.md) (内容产能) 配套阅读: 路线图回答"什么时候能做出来", 内容策略回答"内容从哪来", 本文回答"**怎么把它卖出去, 卖给谁, 卖多少钱**"。

---

## 1. 产品定位

**一句话定位**: 面向家有 4~12 岁孩子、已拥有磁力片玩具的家庭的 B2C 益智教育应用 —— 把一盒"不知道还能搭什么"的磁力片, 变成 500+ 个保证搭得起来的 3D 交互教程。

### 1.1 目标用户画像

| 角色 | 描述 | 核心诉求 |
| --- | --- | --- |
| **付费决策者: 家长** | 25~45 岁, 已为孩子购买磁力片 (家庭存量通常 60~200 片), 重视屏幕时间的"质量" | 孩子玩得久、玩出花样、少求助家长; 屏幕时间可辩护 ("这是在学搭建, 不是在刷视频") |
| **核心使用者: 儿童** | 4~12 岁, 分三个年龄段: 4~6 (跟搭)、7~9 (独立搭)、10~12 (挑战/创作) | 成就感 (搭成了!)、新鲜感 (下一个搭什么)、炫耀感 (给爸妈看成品) |
| **次级场景** | 幼儿园/培训机构的建构区活动、祖辈带娃家庭 | 现成的活动方案, 零备课成本 |

### 1.2 定位边界 (我们是什么 / 不是什么)

- **是**: 实体玩具的数字伴侣 (digital companion)。价值锚定在"手上的磁力片被搭出更多花样", 屏幕只是说明书的进化形态。
- **不是**: 虚拟搭建游戏。我们不与 Minecraft / 虚拟积木 App 竞争屏幕内的乐趣, 而是把孩子从屏幕引导回实体玩具。这是对家长最有说服力的差异点, 所有营销话术围绕它展开。
- **是**: 品牌中立的通用教程库。兼容市面主流"标准尺寸"磁力片 (形状目录数据驱动, 见 `data/tile_catalog.json` 与 `unit_mm` 标定), 不绑定任何单一玩具品牌。
- **不是**: 在线课程/直播课。无真人服务成本, 内容一次生产、无限分发, 毛利结构接近纯软件。

### 1.3 核心用户旅程

```
拥有磁力片 → 下载 App → 按"我有的片数"筛选可搭模型 → 免费搭完第一个模型
    → 解锁成就 → 免费 30 个模型渐进耗尽 → 付费墙 (订阅 / 内容包) → 长期留存: 每周上新
```

关键转化时刻是"**第一次照着教程搭成一个自己以前搭不出来的模型**"。产品所有前 30 分钟的体验 (免费模型选品、难度曲线、步骤粒度) 都为这个时刻服务。

## 2. 收入模式

采用 **Freemium 底座 + 订阅为主 + 内容包为辅 + 硬件捆绑为增量** 的四层结构:

### 2.1 免费层 (获客底座)

- **30 个免费模型**, 以核心片型 (6 基础片型 + 3 变体, 见 `docs/TILE_CATALOG.md`) 为主 —— 免费库 ≥80% 模型只用核心片型, 少量标注"需要扩展装"的橱窗模型展示扩展片形; 难度 1~2 为主、少量难度 3 "橱窗模型" (让用户看见付费库的上限)。
- 免费层永久免费、无广告 (儿童产品不做第三方广告, 见第 6 节合规), 完整功能不阉割 —— 只锁内容, 不锁功能 (物理校验、3D 交互、进度存档对免费用户完全开放)。
- 选品原则: 免费 30 个必须能撑起 2~4 周的新鲜感, 但主题系列刻意"只给系列第一个" (城堡系列给地基、交通系列给小汽车), 制造自然的付费牵引。

### 2.2 订阅 (收入主体, 目标占收入 70%+)

- **全库通行证**: 解锁全部 500+ 模型 + 每周上新 + 全部教学增强功能 (TTS 语音朗读、"我拥有的磁力片"智能推荐)。
- 月度 / 年度两档, 年度为主推 (定价锚点设计见第 3 节), 支持家庭多设备/多儿童档案。
- 订阅逻辑成立的前提是 **持续上新**: 内容管线 (ROADMAP 阶段 2) 必须先于订阅全量推广跑通, 保证"每周 3~5 个新模型"的更新节奏。

### 2.3 一次性内容包 (辅助, 目标占收入 15~20%)

- 按主题系列打包 (如「中世纪城堡包」20 模型、「太空探索包」15 模型、「节日限定包」), 买断制、永久拥有。
- 定位两类人群: ① 反感订阅的家长 (中国市场对买断接受度显著更高); ② 已订阅用户的溢出消费 (限定包可设计为订阅外单独购买的收藏品)。
- 内容包与订阅**不互斥**: 订阅期内可用全部包内容, 退订后已买断的包仍可用 —— 这条规则要在付费页明示, 是建立信任的关键细节。

### 2.4 硬件捆绑合作 (增量, 中长期)

- 与磁力片品牌/白牌厂商合作: 玩具礼盒内附**兑换卡** (3 个月订阅 / 指定内容包), 品牌方按激活量采购兑换码。
- 对品牌方的价值主张: "买我们的磁力片 = 附赠 500+ 教程", 直接提升其货架竞争力与复购 (孩子想搭更大的模型 → 买更多片)。
- 进阶形态: 品牌定制目录 (按其片材尺寸/配件出专属 `tile_catalog`) + 联名系列模型, 收取内容定制费 + 分成。
- 注意: 硬件捆绑是**渠道**不是产品方向, 不自研硬件、不压库存。

### 2.5 明确不做的变现

- 第三方广告 (儿童合规红线 + 品牌调性)。
- 抽卡/盲盒式随机付费 (监管风险 + 家长信任)。
- 真人课程服务 (破坏纯软件毛利结构)。

### 3.2 定价逻辑

- **锚点**: 一盒 100 片磁力片零售价约 ¥150~400。年度订阅 ¥198 ≈ "再买半盒片的钱, 让整盒片多玩三年", 这是付费页的核心话术。
- **对标**: 国内儿童教育类 App 年费主流区间 ¥168~365 (思维/编程/英语类); 我们无真人服务, 定在区间下沿, 以"性价比 + 买断可选"打差异。
- **月/年价比** 刻意拉大 (28×12=336 vs 198), 引导年度; 免费转付费的默认落点是年度档。
- **区域定价**: USD 定价面向国际版 (App Store/Google Play/Steam 自动区域换算); 不做一价全球, 东南亚等市场按购买力下调。
- **退款与试用**: 年度订阅提供 7 天无理由退款 (国内 App 内明示); 不做"免费试用 7 天自动扣费"这类儿童产品口碑雷区。

## 4. 竞争壁垒 (护城河)

竞品现状: 磁力片教程内容目前散落在短视频 (抖音/小红书/YouTube)、纸质说明书与少量图片攻略, **没有结构化、可交互、保证可搭的教程产品**。我们的壁垒按复制难度从高到低:

### 4.1 物理校验器 (最难复制)

- 四大规则 (接地支撑 / 磁力边吸合 / 无重叠 / 重心稳定, 见 [PHYSICS_RULES.md](PHYSICS_RULES.md)) 不仅校验成品, 还**逐步校验教程每个中间状态** —— 保证"照着搭, 不会搭到一半塌"。
- 这是内容质量的工程化保证: 竞品若靠人工出教程, 内容量上不去; 靠 AI 批量生成, 质量守不住。校验器 + 内容管线 = 量与质同时成立, 这是单点最深的壁垒。
- 进阶版 (力矩分析、人因校验, ROADMAP 阶段 4) 将把壁垒延伸到难度 5 大师级模型 —— 这类"看着不可能搭起来"的模型是最强的传播素材, 且竞品最难跟进。

### 4.2 500+ 结构化模型库 (最花时间复制)

- 反批量生成规则与技法分类学 (见 [CONTENT_STRATEGY.md](CONTENT_STRATEGY.md)) 保证 500+ 是"500 个不同的模型"而非"50 个模型 × 10 种换色"。
- 每个模型 = 几何数据 + 分步教程 + 物理质检报告 + 难度定级, 是结构化资产而非视频/图片 —— 可筛选 ("用我有的 80 片能搭什么")、可更新、可本地化, 短视频内容做不到。
- 内容库随时间复利: 竞品从零追赶需重建整条管线 (编辑器 + 校验 + 定级规范 + 实物复核)。

### 4.3 跨平台架构 (核心库零 UI 依赖)

- 核心逻辑 (core/physics/tutorial) 与渲染完全解耦 (`IRenderer` 接口, 见 [ARCHITECTURE.md](ARCHITECTURE.md)), C++20 单代码库覆盖 Windows / macOS / Linux, 移动端只需替换渲染后端 (Metal/GLES)。
- 商业含义: 内容资产一次生产, 全端分发; 新平台边际成本只有渲染层, 竞品若以单平台起家则每扩一端都要重写。

### 4.4 离线优先 (Offline-first)

- 教程、模型、物理校验全部本地运行, 无网可完整使用 —— 匹配真实场景 (客厅地板、幼儿园教室、旅行途中), 也是儿童隐私合规的天然优势 (数据最小化, 见第 6 节)。
- 内容更新为增量包下载, 更新后离线可用; 订阅状态采用宽限期本地凭证, 短期离线不锁内容。
- 对比在线课/流媒体式竞品: 我们没有"网络差 = 产品不可用"的问题, 下沉市场与海外弱网市场直接受益。

### 4.5 壁垒的自增强循环

```
物理校验器 → 内容量产不失控 → 模型库规模领先 → 用户/订阅增长
    → 内容再投入 + UGC 生态 (阶段 4) → 库规模进一步拉开 → 循环
```

## 5. 市场进入策略 (Go-to-Market)

### 5.1 总体节奏

1. **桌面端先行** (与 ROADMAP 阶段 1~3 对齐): Windows/macOS 安装包直发 + Steam (国际), 验证付费闭环与留存, 打磨内容库到 250。
2. **移动端全量** (阶段 3 末~4): iOS App Store (含儿童分类) + Google Play (国际) + 国内安卓商店 (华为/小米/OPPO/vivo/应用宝), 移动端才是 B2C 规模化的主战场 —— 客厅场景里 iPad/手机远比电脑常见。
3. **中国市场特化** 与 **品牌合作** 并行推进 (见下)。

### 5.2 应用商店策略

- **Apple App Store**: 上"儿童"分类获取家长信任与编辑推荐位, 但需满足其儿童类严格规则 (无第三方广告/追踪 SDK、家长门控); ASO 关键词围绕"磁力片 教程 搭建 积木"。
- **Google Play**: 加入 "Designed for Families" 计划, 面向海外市场。
- **Steam (桌面国际版)**: 教育/休闲分类, 买断制"完整版" (等价大内容包) 可能比订阅更符合 Steam 用户习惯 —— 同一内容库, 按渠道调整商业化皮肤。
- **国内安卓商店**: 需逐家完成资质与审核 (软著、ICP 备案等, 见第 6 节); 优先华为 (平板家庭用户占比高) 与应用宝。

### 5.3 中国市场: 微信小程序 vs 独立 App

结论: **独立 App 为主体, 微信小程序做"试玩 + 导流", 不做完整产品**。

| 维度 | 微信小程序 | 独立 App |
| --- | --- | --- |
| 3D 渲染能力 | WebGL, 性能受限, 大模型 (数百片 + 描边高亮) 帧率难保证 | 原生 OpenGL/Metal, 完整体验 |
| 离线能力 | 弱 (缓存受限), 与离线优先卖点冲突 | 完整离线 |
| 订阅/虚拟支付 | iOS 端虚拟支付受限, 政策波动大 | 应用内购流程成熟 |
| 获客 | **强**: 家长群/朋友圈裂变零门槛, 无需下载 | 需要下载转化 |
| 结论 | 承载 3~5 个轻量免费教程 + "拍照识别你的磁力片存量" 之类的传播钩子, 一键跳转 App 下载 | 承载全部付费与核心体验 |

- 私域配套: 微信公众号 (每周新模型预告 + 搭建成果征集)、企业微信家长群 (大促与续费触达)。
- 内容种草主阵地: **小红书 + 抖音**。母婴/玩具类目 KOC 投放"孩子跟着 App 搭出 XX"的成品视频; 大师级模型 (难度 5) 是天然的爆款素材。转化路径: 短视频 → 小程序试玩 → App 下载 → 免费 30 模型 → 订阅。

### 5.4 磁力片品牌合作

- **合作对象分层**: 国内头部品牌 (自有内容能力弱、渠道强) → 白牌/跨境卖家 (量大、决策快, 兑换卡最易切入) → 国际品牌 (周期长, V2 后再谈)。
- **合作形态** (按投入从轻到重): ① 盒内兑换卡 (见 2.4); ② 联名内容包 (品牌方出题材, 我们出内容, 收定制费 + 挂品牌 logo 于该系列); ③ 定制形状目录 (适配其非标配件, 技术上由数据驱动目录直接支持)。
- **红线**: 任何合作不签独家 (品牌中立是定位根基); 联名内容中的品牌露出仅限该品牌合作系列内。
- 线下延伸: 与玩具集合店/亲子空间合作"搭建挑战角" (平板 + 磁力片 + App), 低成本获客与品牌曝光。

## 6. 法务与合规

### 6.1 商标与 IP 规避 (内容红线)

- **禁止在模型名称、教程文案、商店素材、营销物料中使用受保护的品牌与 IP 名称**。明确的负面清单 (随内容库扩展持续维护):
  - 玩具品牌: Magna-Tiles、MAGNA-QUBIX、PicassoTiles、Connetix、Playmags 及国内品牌注册商标 —— 一律以通用词"磁力片/磁力积木 (magnetic tiles)"指代。
  - 影视/动画 IP: Paw Patrol (汪汪队立大功)、迪士尼/漫威角色、奥特曼、小猪佩奇等 —— 模型题材用通用主题替代 (如"救援小狗基地"而非"汪汪队瞭望塔"), 且**造型本身也不得实质性复刻**受版权保护的标志性形象 (规避商标之外的著作权风险)。
- 内容入库流程增加 **IP 审查项**: 模型名 / 文案 / 造型三查, 与物理质检并列为入库门禁 (落入 CONTENT_STRATEGY 的生产管线检查单)。
- 兼容性表述规范: 可以陈述客观事实 ("适配市面通用标准尺寸磁力片"), 不得使用"Magna-Tiles 官方教程"等暗示背书的表述; 如需列出兼容品牌名, 仅限对比表格中的指名性合理使用 (nominative fair use), 并加"各商标归其所有者"声明。
- 自有商标: 尽早在中国 (第 9/28/41 类) 与美国注册 "MagTile Studio" 文字与图形商标; 注意 "MagTile" 与既有品牌的近似性检索, 如有风险预留备选名。

### 6.2 内容授权

- **出方向**: 官方模型库版权归公司所有; 用户协议明确教程内容仅限个人/家庭/课堂非商业使用, 培训机构商用需另行授权 (预留 B 端授权收入接口)。
- **入方向 (UGC, 阶段 4)**: 创作者上传即授予平台全球范围的展示/分发/改编许可, 创作者保留署名; UGC 入库前过同一套 IP 审查 + 物理质检; 建立侵权投诉-下架通道 (避风港流程)。
- **联名内容**: 品牌联名系列的 IP 边界、使用期限、下架义务写入合作合同, 到期模型可平滑替换为去品牌化版本 (数据驱动内容天然支持)。
- 第三方组件许可 (nlohmann/json MIT、GLFW zlib/libpng、Dear ImGui MIT) 随安装包附许可声明文件。

### 6.3 儿童隐私 (COPPA / 中国《儿童个人信息网络保护规定》/ GDPR-K)

设计原则: **数据最小化到"几乎不收集"** —— 离线优先架构使产品核心功能完全不依赖个人信息, 这是合规的结构性优势, 要作为卖点明示给家长。

- **默认零账号可用**: 免费内容与本地进度无需注册; 只有购买订阅/跨设备同步才需要账号, 且账号由**家长**创建。
- **中国合规** (《儿童个人信息网络保护规定》、《个人信息保护法》第 31 条: 14 周岁以下为敏感个人信息):
  - 收集儿童信息前取得监护人**单独同意**; 设立儿童个人信息保护专员; 制定专门的儿童隐私政策 (独立成文, 通俗表述)。
  - 儿童档案仅存昵称/年龄段 (4~6/7~9/10~12) 用于难度推荐, 不收集真实姓名、照片、精确位置; 昵称本地生成建议词, 避免诱导填写真名。
  - App 备案 (工信部 ICP 备案)、软件著作权登记为国内商店上架前置项; 如未来加入社区/UGC, 按《未成年人网络保护条例》补充内容审核与防沉迷评估。
- **COPPA (美国)**: 13 岁以下用户信息收集需可验证家长同意 (VPC); 策略是**根本不触发** —— 国际版同样零账号可玩, 购买走商店支付 (Apple/Google 作为交易主体), 不集成第三方广告/行为分析 SDK; 崩溃统计等遥测走匿名聚合并提供家长开关。
- **GDPR-K (欧盟)**: 同源策略覆盖; 数据处理清单、DPA、被遗忘权响应流程在国际版上线前备齐。
- **家长门控**: 所有付费入口、外链、设置页均置于家长验证之后 (随机算术题等 App Store 儿童类标准做法)。

## 7. 团队角色

按"内容产能是第一瓶颈" (见 ROADMAP 风险节) 配置, 核心编制 8~11 人:

| 角色 | 人数 (MVP→Scale) | 职责 | 关键要求 |
| --- | --- | --- | --- |
| **内容设计师** | 1 → 3 | 用可视化编辑器设计模型与分步教程, 执行难度定级与步骤粒度规范, 维护主题矩阵 | 玩具/幼教背景优先; 空间想象力; 产出以"模型/周"考核 |
| **3D 美术** | 1 → 2 | 商店与营销渲染图、成品展示动画、UI 视觉、内容包封面 | 实时渲染审美; 能与工程协作定义材质/描边风格 |
| **实物质检 (QA Physical Tester)** | 1 → 2 (可兼职起步) | 按教程用真实磁力片逐步复搭, 验证物理校验器盲区 (手感、磁力强度差异、儿童可操作性); 难度 4+ 模型入库必检 | 细致耐心; 维护多品牌片材样品库; 反馈直接回灌校验器规则 |
| **开发工程师** | 3 → 4 | C++ 核心/渲染 (1~2)、编辑器与工具链 (1)、平台与商业化 (支付/账号/分发, 1) | C++20 + 图形; 工具链岗直接决定内容产能 |
| 产品/运营 (兼) | 1 | 付费漏斗、商店运营、KOC 投放、家长社群 | 母婴/教育类目投放经验 |
| 外包/顾问 | 按需 | 儿童隐私法务顾问、TTS 配音、本地化翻译 | 不设全职编制 |

- 配置原则: **工具优先于人力** —— 编辑器每提效一倍, 等价于多雇一名内容设计师; 工程编制向工具链倾斜。
- 实物质检是本产品特有的岗位: 物理校验器保证几何/力学正确, 但"5 岁孩子的手能不能按这个顺序放进去"只有真人复搭能验证, 该岗位的反馈清单是校验器人因规则 (ROADMAP 阶段 4) 的数据来源。

## 8. 里程碑: MVP → V1 → V2 → Scale

以**技术与内容交付物**定义阶段边界 (不做日历排期), 与 ROADMAP 工程阶段的映射关系如下:

### MVP (≈ ROADMAP 阶段 1) — "可演示、可验证需求"

- **交付物**: 桌面端 3D 交互教程 (GLFW/OpenGL 后端, 已具备) + 20 个免费模型 + 本地进度存档。
- **商业动作**: 不收费。小红书/抖音种子内容投放, 微信群招募 50~100 个种子家庭。
- **通过标准**: 非开发者家庭无指导跟完教程; 种子用户周均完成 ≥ 2 个模型; 收集到"愿意为全库付多少钱"的定价访谈样本 ≥ 30 份。

### V1 (≈ ROADMAP 阶段 2 + 阶段 3 的付费闭环) — "可收钱"

- **交付物**: 可视化模型编辑器投产 (新模型 ≤ 0.5 人日); 内容库 100+; 免费 30 / 订阅 / 首批 3 个内容包上线; 账号与家长门控; Windows/macOS 安装包 + 自动更新; 微信小程序试玩版导流。
- **商业动作**: 定价体系 (第 3 节) 全量生效; 首个品牌兑换卡试点 (单品牌、小批量)。
- **通过标准**: 付费闭环跑通且退款率 < 3%; 免费→付费转化 ≥ 4% (见第 9 节基线); 内容周更节奏稳定 (≥ 3 模型/周) 连续 8 周。

### V2 (≈ ROADMAP 阶段 3 完整 + 移动端) — "可规模投放"

- **交付物**: 内容库 250+ (难度 1~4 全覆盖); iOS/Android 版本 (渲染层 Metal/GLES 移植) 过儿童类目审核; TTS 语音朗读、"我拥有的磁力片"筛选推荐; 多语言 (简中首发 + 英文); 崩溃率 < 0.1%。
- **商业动作**: 移动商店全量上架 + ASO; KOC 投放放量; 品牌联名内容包 ≥ 2 个; 国际版 (Steam + Google Play) 开售。
- **通过标准**: 移动端 DAU 超过桌面端; 订阅年度档占新增付费 ≥ 60%; 单位获客成本 (CAC) < 首年订阅毛利。

### Scale (≈ ROADMAP 阶段 4) — "生态与壁垒"

- **交付物**: 内容库 500+ (官方 400+ / 精选 UGC 100+); 进阶物理校验 (力矩/人因) 支撑难度 5 大师级模型; 编辑器对高级用户开放 + UGC 审核管线; AI 辅助生成教程草稿进入内容管线。
- **商业动作**: UGC 创作者分成计划; 品牌合作从兑换卡升级为定制目录/联名宇宙; 机构版 (幼儿园/机构授权) 试点。
- **通过标准**: UGC 周投稿量稳定且过审率可控; 订阅续费率与 LTV 达标 (见第 9 节); 内容上新中 UGC + AI 辅助占比 ≥ 30% (边际内容成本下降)。

## 9. 关键指标 (KPI)

### 9.1 北极星指标

**每周完成教程数 (Weekly Tutorials Completed)** —— 同时反映活跃、内容质量与实体玩具使用率, 是"数字伴侣"定位的直接度量。所有其他指标围绕它解释。

### 9.2 指标体系与基线

| 层 | 指标 | 定义 | 阶段目标 (V1 → V2 → Scale) |
| --- | --- | --- | --- |
| 活跃 | **DAU / MAU** | 日活/月活; 附 DAU/MAU 粘性比 | 粘性比 ≥ 15% → 20% → 25% (儿童产品周末峰值明显, 另看 WAU) |
| 激活 | 首模型完成率 | 新用户 72 小时内完成第 1 个教程的比例 | ≥ 40% → 50% → 55% |
| 质量 | **教程完成率** | 开始的教程中搭完最后一步的比例 (按难度分层看) | 整体 ≥ 60%; 难度 1~2 ≥ 75%; 单模型 < 40% 触发内容返工 |
| 变现 | **订阅转化率** | 免费用户 → 付费 (订阅或内容包) 的 30 日转化 | ≥ 4% → 6% → 8% |
| 变现 | ARPPU / LTV | 付费用户年均收入 / 生命周期价值 | LTV ≥ 3 × CAC 为投放放量前提 |
| 留存 | **订阅流失率 (Churn)** | 月度订阅的月流失 / 年度订阅的到期续费率 | 月订阅月流失 ≤ 8%; 年订阅续费率 ≥ 45% → 55% |
| 留存 | D7 / D30 留存 | 新用户第 7/30 日回访 | D7 ≥ 25%, D30 ≥ 12% (儿童教育类中位以上) |
| 内容 | 上新消费率 | 新模型上线 14 日内被订阅用户开搭的比例 | ≥ 30%; 持续走低预示内容与用户口味脱节 |

### 9.3 指标使用规则

- **归因链**: 教程完成率 ↓ → 先查内容 (步骤粒度/难度定级) 再查产品 (交互/性能); 订阅流失 ↑ → 先查上新节奏与上新消费率。北极星下滑时按 激活 → 质量 → 内容 顺序排查。
- **合规约束**: 所有指标采集遵守第 6.3 节 —— 匿名设备级聚合, 不做儿童个体行为画像, 不接第三方分析 SDK; 遥测提供家长关闭开关, 关闭率本身作为信任度监控指标。
- **反虚荣**: 不以下载量为目标指标 (兑换卡渠道会天然推高); 内部汇报以北极星 + 订阅转化 + 续费率三项为准。
