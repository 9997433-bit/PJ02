## 给家长的一页纸（摘要）

1. **我们不收集孩子的个人信息。** 应用没有账号系统、没有广告、没有任何第三方统计/分析/推送 SDK，儿童界面不存在任何输入姓名、照片、语音、位置的地方。
2. **应用完全离线可用。** 当前版本零网络代码——不联网就没有数据可以被传走。
3. **设备上只保存这些数据**（全部留在您自己的设备里，不上传）：
   - 搭建进度与成就（搭到第几步、什么时候完成、累计玩了多久）；
   - 收藏标记；
   - 家里磁力片库存（片型 → 数量，由家长录入）；
   - 界面设置（字号、减少动效、步骤朗读开关、年龄段模式）。
4. **家长说了算。** 家长中心（需通过家长门验证）的「隐私与数据」区可以：
   - 查看数据存放的具体文件路径；
   - **导出**全部数据为一份可读的 JSON 文件留档；
   - **清除**全部本地数据（有二次确认；清除后应用回到首次启动状态）。
5. **付费（未来版本）只会出现在家长门之后**，儿童界面不显示任何价格；支付由应用商店平台完成，我们不经手支付信息。

## 正文

### 1. 我们是谁

MagTile Studio（磁力片工坊）是一款面向 4–12 岁儿童的磁力片搭建教程应用。运营主体信息（公司全称、注册地址、联系方式、儿童个人信息保护专员）将在正式版发布前于本节补全。<!-- 法务定稿项 -->

### 2. 我们处理哪些信息

**当前版本默认不收集、不传输任何个人信息。** 应用在您的设备本地保存以下数据（存放于应用私有目录的单个存档文件 `progress.db`，各平台具体路径可在应用内「家长中心 → 隐私与数据」查看）：

| 数据 | 内容 | 是否上传 |
|------|------|----------|
| 搭建进度 | 模型标识、当前步骤、完成时刻、累计游玩时长 | 否 |
| 成就 | 成就标识与首次解锁时刻 | 否 |
| 收藏 | 模型收藏标记 | 否 |
| 磁力片库存 | 片型与数量（家长录入） | 否 |
| 界面设置 | 字号档位、减少动效、步骤朗读开关、年龄段模式 | 否 |

以上数据不含任何可识别孩子身份的信息。「年龄段模式」（4–6 / 7–9 / 10–12 三档）由家长选择，仅作为本地界面开关存储，不与任何标识符关联、不上传。

### 3. 我们承诺永不收集

- 儿童姓名、生日、照片、语音、视频、通讯录、位置（含粗略位置）；
- 设备广告标识符（IDFA / GAID）；
- 儿童界面的任何自由文本输入（产品上根本不设输入框）；
- 行为画像与跨应用追踪数据。

### 4. 第三方 SDK 与广告

- 应用**不含广告**，不向儿童展示任何形式的广告或诱导性推广。
- 儿童可达的应用构建中**不集成**任何第三方统计/分析（如友盟、Firebase Analytics、AppsFlyer）、广告、第三方推送、社交分享或第三方登录 SDK。
- 应用的全部依赖为本地组件（内嵌 SQLite 数据库与系统图形/语音接口），无任何第三方数据服务。

### 5. 网络与数据传输

当前版本**零网络代码**，完全离线运行。未来版本如引入网络功能（订阅校验、可选云同步、可选崩溃诊断），将：

- 逐项在应用内向家长明示并取得同意后才启用（默认关闭）；
- 全部连接使用 TLS 1.2 及以上加密；
- 云同步等涉及儿童相关数据的功能仅由家长账号开通，并遵守届时更新的本政策与《儿童个人信息保护声明》；
- 在中国大陆运营的网络服务将依法完成备案并将数据存储于境内合规云。

### 6. 家长的权利：查看、导出、删除

家长中心（需通过家长门验证）的「隐私与数据」区提供：

- **查看**：展示数据收集口径与存档文件的具体路径；
- **导出**：一键把全部本地数据导出为一份人类可读的 JSON 文件（含进度、成就、库存、设置），便于留档或迁移；
- **删除**：一键清除全部本地数据（二次确认后原子执行），清除后应用回到首次启动状态。卸载应用同样会删除应用私有目录中的全部数据（平台允许范围内）。

未来引入家长账号与云同步后，家长可在同一入口删除云端数据或注销账号。

### 7. 数据安全

- 全部数据存放于应用私有目录（Android `filesDir`、Windows `%APPDATA%`、macOS `Application Support`、Linux XDG 数据目录），不落公共存储；
- 本地数据不含个人身份信息；未来如存储家长账号凭证，将升级为加密存储（SQLCipher / 平台安全设施）；
- 模型内容为纯数据 JSON，解析前经严格校验，永不作为代码执行；
- 应用与内容更新只接受签名验证通过的包。

### 8. 儿童个人信息保护（COPPA / 中国《儿童个人信息网络保护规定》）

- 我们默认不处理儿童个人信息，因此不触发可验证家长同意（VPC）流程；未来任何涉及儿童个人信息的功能上线前，都将先取得监护人的单独同意；
- 设置、付费入口、外部链接、数据操作全部置于家长门之后，儿童无法独自触达；
- 我们将在商用发布前指定儿童个人信息保护专员，并发布独立的《儿童个人信息保护声明》；<!-- 法务定稿项 -->
- 如发生数据安全事件，我们将按法规要求及时告知监护人并向主管部门报告。

### 9. 本政策的变更

数据实践发生任何变更（包括新增数据字段、引入网络功能）时，我们将同步更新本政策、应用内摘要与应用商店数据安全表单（三处一致），重大变更将在应用内向家长显著提示。

### 10. 联系我们

- 隐私与安全问题反馈：`security@`（域名在定稿时补全）；<!-- 法务定稿项 -->
- 我们承诺在 48 小时内响应外部安全报告。
