## 1. 第 0 步: 运营主体信息定稿 (L4)

### 1.1 为什么它是一切的前置

国内上架链条上有**五处必须是同一主体** (营业执照上的公司全称):

1. 软著登记的**申请人** (§2);
2. App 备案与网站备案的**备案主体** (§3);
3. 隐私政策与《儿童个人信息保护声明》的**署名主体**
   ([PRIVACY_POLICY_DRAFT.md](PRIVACY_POLICY_DRAFT.md) §1);
4. 各商店**企业开发者账号**的实名认证主体 (§4) —— 商店后台会把
   账号主体与软著证书、备案号做联查, 任一对不上即卡审
   ([CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §3/§8);
5. 代码签名证书的**申请主体** (Windows Authenticode / Apple Developer ID,
   [V1_LAUNCH_CHECKLIST.md](V1_LAUNCH_CHECKLIST.md) §3 D4/D5)。

主体一旦办完再变更, 代价是: 软著变更登记 + 备案主体变更 (先变更后
发版) + 商店账号主体大多**不可直接变更、需重新注册认证**。所以定稿
必须在第一批办理动作启动之前完成, 且此后视为冻结项。

### 1.2 要定稿的字段与回填位置

| # | 字段 | 回填到哪 (定稿后立即做) | 用在哪 |
| --- | --- | --- | --- |
| 1 | 公司全称 (营业执照名称) | [PRIVACY_POLICY_DRAFT.md](PRIVACY_POLICY_DRAFT.md) §1 | 软著申请人 / 备案主体 / 商店账号 / 签名证书 |
| 2 | 注册地址 | [PRIVACY_POLICY_DRAFT.md](PRIVACY_POLICY_DRAFT.md) §1 | 备案表单 / 邓白氏编码 / Google 付款资料 (须与邓白氏库一致, §4.4) |
| 3 | 法定代表人 + 备案负责人 (姓名 / 身份证 / 手机 / 邮箱) | 公司资质库留档 | 各平台实名认证、打款验证、备案真实性核验 |
| 4 | 对公银行账户 | 公司资质库留档 | 华为 / 应用宝 / 小米等打款验证 (§4), 商店收款 |
| 5 | 官网域名 | [STORE_LISTING.md](STORE_LISTING.md) §2 官网 + §8.1 URL 占位 | 隐私政策 / 儿童声明托管 URL, 网站备案对象 |
| 6 | 联系邮箱域名 (`support@` / `security@`) | [STORE_LISTING.md](STORE_LISTING.md) §2 联系邮箱; [PRIVACY_POLICY_DRAFT.md](PRIVACY_POLICY_DRAFT.md) §10 | 商店必填联系方式 / 隐私政策联系通道 |
| 7 | 儿童个人信息保护专员 (人选 + 对外联系通道) | [PRIVACY_POLICY_DRAFT.md](PRIVACY_POLICY_DRAFT.md) §1/§8; 《儿童个人信息保护声明》 | 国内儿童向应用资质项 ([CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §4) |

### 1.3 对隐私政策的影响 (为什么 V2 定稿卡在 L4)

[PRIVACY_POLICY_DRAFT.md](PRIVACY_POLICY_DRAFT.md) 目前是草稿, 其全部
「法务定稿项」都直接依赖本节字段:

- **§1「我们是谁」**: 运营主体全称、注册地址、联系方式、儿童个人信息
  保护专员 —— 即上表字段 1/2/6/7, 一个不定, 隐私政策就无法从
  「草稿」转「定稿」;
- **§10「联系我们」**: `security@` 的域名 = 上表字段 6, 域名不定
  邮箱开不出来;
- **生效日期**: 随法务定稿一并落款;
- **《儿童个人信息保护声明》**独立成文的署名主体与专员联系通道
  同源于本节 (声明本身由法务顾问起草,
  [CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §4)。

下游连锁: 隐私政策定稿 (V2) → 才能发布网页版到 `/privacy` 与
`/children-privacy` (§3.1 事项 B 的域名 + 网站备案是其托管前提) →
才能满足「网页版 = 应用内摘要 = 商店填报」三处一致
([STORE_LISTING.md](STORE_LISTING.md) §8.1) → 商店提交才不被隐私项卡住。
即 **L4 未定稿 = V2 / A5 / D5 / 全部 §2~§4 事项同时被阻塞**, 这是
本文把它排为第 0 步的原因。

### 1.4 执行动作

- [ ] 若公司尚未注册: 完成公司设立 (营业执照 + 对公账户 + 法人实名),
      经营范围建议覆盖「软件开发、软件销售」类目 (备案与商店审核会
      核对经营范围与应用服务内容的相关性,【以工商与管局要求为准】);
- [ ] 上表 7 个字段逐项定稿, 落一份《运营主体信息定稿单》归档公司
      资质库 (后续所有表单从定稿单抄写, 禁止即兴填写);
- [ ] 注册官网域名 (国内注册商, 域名实名认证主体 = 公司全称, 见 §3.1);
- [ ] 开通 `support@` / `security@` 企业邮箱;
- [ ] 回填字段到 [PRIVACY_POLICY_DRAFT.md](PRIVACY_POLICY_DRAFT.md) 与
      [STORE_LISTING.md](STORE_LISTING.md) 占位处, 启动法务定稿流程
      (V1_LAUNCH_CHECKLIST §5 V2)。

## 2. 软件著作权登记 (L1)

事项定义与阻塞理由见 [CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md)
§2 (P0, 全部国内商店必查, **全清单周期最长的串行项, 最先启动**)。

### 2.1 在哪办、多少钱、多久

| 项 | 内容 |
| --- | --- |
| 办理机构 | 中国版权保护中心 (CPCC), 官网 `www.ccopyright.com.cn`, 全程线上无纸化【以官网为准】 |
| 官费 | **0 元** (财政部已停征软件著作权登记费); 委托代理或加急支付的是服务费 |
| 法定时限 | 受理之日起 **60 日内**审查完成 (《计算机软件著作权登记办法》第 20 条), 约合 30~40 个工作日; 实际随排队浮动 |
| 加急 | 有付费加急通道 (数个工作日至数周不等, 资格与费用【以官网为准】); 以商店提审目标节点倒排, 普通件覆盖不了就加急 |
| 补正 | 收到补正通知后 **30 日内**须补正, 逾期视为撤回申请 —— 材料一次备齐是最大的省时项 |

### 2.2 材料清单 (提交前逐项打勾)

- [ ] **申请表**: 官网系统在线填写后生成 PDF, 加盖公章上传。关键字段:
  - 软件全称: 建议「MagTile Studio 磁力片工坊软件 V1.0」—— 名称须以
    「软件」或「系统」结尾, 且**必须能与商店应用名对应**
    ([STORE_LISTING.md](STORE_LISTING.md) §2 应用名, 对应关系断裂是
    最常见驳回原因, [CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §2);
  - 版本号: V1.0; 开发完成日期、发表状态如实填写 (提交后不可改);
  - 申请人: 公司全称 (§1 定稿单), 开发方式「独立开发」、权利取得
    「原始取得」、权利范围「全部权利」;
- [ ] **营业执照副本**彩色扫描件 (加盖公章);
- [ ] **源程序鉴别材料**: 前 30 页 + 后 30 页连续源代码 (总量不足
      60 页则全交), 每页 ≥50 行, 末页为程序结尾; 页眉标注
      「软件名称 + 版本号 + 页码」; 从自研代码截取
      (口径见 [CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §2),
      **不含 `third_party/` 任何第三方库代码**, 代码内出现的版权注释
      须与申请人一致;
- [ ] **文档鉴别材料**: 操作手册 / 用户手册任选其一, 前 30 页 +
      后 30 页 (不足 60 页全交), 每页 ≥30 行, 页眉同上; 含主界面
      截图与功能说明, 截图必须为真实界面
      ([STORE_LISTING.md](STORE_LISTING.md) §5 红线, 不得合成);
- [ ] (如委托代理) 代理委托书。

### 2.3 分步流程

1. 官网注册账号并完成**企业实名认证** (营业执照 + 法人信息);
2. 在线填写《计算机软件著作权登记申请表》(R11 表), 保存生成 PDF,
   盖章后上传;
3. 上传源程序与文档鉴别材料 (PDF)、营业执照扫描件;
4. 确认提交, 下载**受理回执** (带查询码, 用于跟踪进度);
5. 如需加急: 按官网指引提交加急申请与理由并缴费【以官网为准】;
6. 跟踪审查进度; 收到**补正通知**立即处理 (30 日时限, 常见补正类型
   见 §2.4), 补正后重新计时;
7. 审查通过后领取**电子证书** (+ 如需纸质证书按官网申领), 彩色
   扫描件归档公司资质库;
8. 证书关键信息 (登记号 / 软件全称 / 版本号) 登记进
   [CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §9 总控清单,
   并更新 [V1_LAUNCH_CHECKLIST.md](V1_LAUNCH_CHECKLIST.md) §9 L1 状态。

### 2.4 常见补正 / 驳回与规避

| 坑 | 规避动作 |
| --- | --- |
| 软著名称与商店应用名对不上 | 登记名称包含商店短名「磁力片工坊」(§2.2 建议名已覆盖) |
| 代码与文档不一致 (文档截图 / 功能与代码对不上) | 文档从真实版本截图, 提交前工程侧对一遍 |
| 版本号打架 (申请表 / 页眉 / 文档内版本不一) | 三处统一 V1.0, 提交前专人复核 |
| 含第三方代码或他人版权声明 | 截取范围排除 `third_party/`, 全文检索 `copyright` 核对署名 |
| 页数 / 行数不达标 | 按 §2.2 数字硬核对 (程序每页 ≥50 行, 文档每页 ≥30 行) |

## 3. App 备案 (工信部 ICP) (L2)

事项定义与法规依据见 [CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md)
§3 (P0, 2023 年 9 月起各商店强制校验备案号)。

### 3.1 先分清三件事 (都要办, 别混)

| 事项 | 对象 | 办理入口 | 本项目是否需要 |
| --- | --- | --- | --- |
| A. **App 备案** | 应用本体 (包名 `com.magtile.studio` + 签名) | 云平台备案系统或应用分发平台 | **需要** (国内商店上架硬前置) |
| B. **网站 ICP 备案** | 官网域名 (隐私政策托管页) | 域名 / 服务器所在云平台备案系统 | **需要** (隐私 URL 托管在境内服务器就必须备, [CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §5) |
| C. **公安联网备案** | 已备案的网站 / App | 全国互联网安全管理服务平台 | **需要** (开通之日起 30 日内, P1) |

A 与 B 可同主体同通道办理 (同一云平台账号下先主体备案一次, 再分别
提交网站与 App); C 在 A/B 取号后 30 日内补办。

### 3.2 前置条件 (缺一不能提交)

- [ ] 运营主体定稿 (§1), 云平台账号完成**企业实名认证**;
- [ ] 域名已注册且**实名认证主体 = 备案主体** (事项 B);
- [ ] 境内云服务器 / 托管资源就位 (备案要求服务商具备 IDC/ISP 资质,
      阿里云 / 腾讯云 / 华为云均可; 隐私政策静态页一台最低配即够);
- [ ] **Android release 签名就位** (事项 A 的硬前置): 按
      [../platforms/android/SIGNING.md](../platforms/android/SIGNING.md)
      生成正式 keystore 并出一版 release 包 —— 备案要填**包名、签名
      证书公钥、签名 MD5**, 三者与提审包必须一致, 换签名要变更备案
      ([CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §3);
      特征信息可用云平台「备案辅助工具 / 智能助理」上传 release APK
      自动提取, 或由工程侧导出;
- [ ] 备案负责人手机 / 邮箱可用 (要接初审电话核验与工信部短信核验)。

### 3.3 分步流程 (以云平台通道为例)

1. 登录云平台备案系统 (阿里云 / 腾讯云备案控制台);
2. **主体备案** (首次): 填公司信息 + 法人与备案负责人信息, 上传
   营业执照与证件, 完成真实性核验 (人脸识别等, 按系统指引);
3. **提交 App 备案信息**: App 名称 (与商店应用名一致)、包名
   `com.magtile.studio`、签名证书公钥、签名 MD5、服务类型 (教育 /
   工具类)、**面向未成年人使用的标记位按实勾选**; 申报口径: 当前
   版本零网络代码、不含自建服务端域名
   ([CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §3;
   [PRIVACY_POLICY_DRAFT.md](PRIVACY_POLICY_DRAFT.md) §5); 同一订单
   或并行提交官网域名的**网站备案** (事项 B);
4. **服务商初审**: 1~2 个工作日, 审核专员电话核验 —— 保持备案负责人
   电话畅通, 未接通会被驳回;
5. **工信部短信核验**: 初审通过后收到工信部短信, **24 小时内**按
   短信指引完成核验;
6. **管局审核**: 省通信管理局终审, 最长约 20 个工作日 (各省浮动,
   全流程合计约 3~22 个工作日【以官网为准】);
7. **取号**: 备案号格式「X ICP 备 XXXXXXXX 号-XA」(App) 与
   「X ICP 备 XXXXXXXX 号-X」(网站), 短信 / 邮件通知。

### 3.4 取号后必做

- [ ] **应用内展示备案号** (工程项, 交
      [V1_LAUNCH_CHECKLIST.md](V1_LAUNCH_CHECKLIST.md) 工程侧执行):
      落点「家长中心 / 设置 → 关于」页, 与隐私政策入口同屏
      ([CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §3, 商店抽查项);
- [ ] 官网页脚展示网站备案号并链接工信部查询页;
- [ ] 各商店后台回填备案号 (应用宝 / 小米 / 华为等与工信部系统自动联查);
- [ ] 30 日内完成**公安联网备案** (事项 C), 官网页脚补公安备案号;
- [ ] 建立变更台账: App 名称 / 包名 / 签名 / 主体任一变更, **先变更
      备案再发版**, 写入发版检查流程。

[CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §8。本节只管
「把账号开出来」。

### 4.1 通用原则

- **主体一致**: 全部账号用 §1 定稿的公司主体实名, 与软著 / 备案主体
  同一 (§1.1 铁律);
- **账号是公司资产**: 注册邮箱 / 手机 / 登录微信或 QQ 用公司管理的
  号码与邮箱 (如 `dev@` 企业邮箱), 不绑员工个人号; 账号凭据入公司
  密码库, 至少两人可恢复;
- **对公打款验证是共同模式**: 华为 / 应用宝 / 小米等企业认证都以
  「平台向对公账户打小额随机款, 回填金额 (与附言随机码)」为主流方式,
  办理周内财务侧要有人盯对公账户流水;
- 各平台表单与费用随政策变动, 下述数字均【以官网为准】。

### 4.2 华为 AppGallery (国内优先级最高)

入口: `developer.huawei.com` → 注册华为账号 → 实名认证选**企业开发者**。

1. 准备: 营业执照 (信息与国家企业信用公示系统一致)、法定代表人
   身份信息、对公银行账户;
2. 认证方式三选一:
   - **对公打款** (推荐, 儿童向应用属敏感类目时可能仅此一种可选
     【以官网为准】): 填企业信息 + 对公账户 → 30 分钟~3 个工作日内
     收到一笔 <1 元打款、附言含 6 位随机码 → 回填金额与随机码,
     系统即时审核;
   - 企业资料人工审核: 营业执照扫描件 + 法人证件 / 人脸识别,
     约 1~2 个工作日;
   - 华为云授权: 账号已在华为云完成企业实名则即时复用;
3. 认证免费; 认证通过后在 AppGallery Connect 创建应用 (包名
   `com.magtile.studio`);
4. 上架付费应用 / IAP 需另行签署商户服务协议并配置对公收款
   【以后台为准】(付费闭环对接见
   [V1_LAUNCH_CHECKLIST.md](V1_LAUNCH_CHECKLIST.md) §2 B3)。

### 4.3 应用宝 (腾讯, 国内优先级第二)

入口: 腾讯开放平台 (`open.tencent.com`), 用微信或 QQ 登录 —— 该
微信 / QQ 号即账号载体, **必须用公司管理的号**
([STORE_LISTING.md](STORE_LISTING.md) §4.2 已提示)。

1. 登录后选择**企业开发者认证**: 填公司信息、上传营业执照、法定
   代表人信息;
2. 验证: 对公打款小额验证 (随机金额回填) 或法人扫码核验, 按后台
   指引【以后台为准】;
3. 认证通过后创建应用; 提审时软著证书上传 + **备案号强制校验**
   (与工信部系统自动核验,
   [CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §8.5), 所以
   应用宝提审必须排在 L1/L2 取证之后。

### 4.4 Google Play (国际分发)

入口: `play.google.com/console`。注意: Play 商店不面向中国大陆分发,
该账号服务国际版 ([STORE_LISTING.md](STORE_LISTING.md) §3); 中国大陆
公司主体可以注册。

1. **先办邓白氏编码 (D-U-N-S)**: 组织账号强制要求, 免费, 在邓白氏
   官网查询公司是否已有编码, 没有则申请 —— **最长约 30 天, 是
   Google Play 开户的最慢一步, 与软著同批启动**; Google 付款资料中
   的组织法定名称 / 地址 / 电话必须与邓白氏数据库**完全一致**
   (即 §1 定稿字段 1/2);
2. 准备: 组织自有域名邮箱的 Google 账号 (开启两步验证, 不用个人
   Gmail)、公司注册文件 (营业执照)、账号所有人身份证件、可支付
   25 美元的国际信用卡;
3. 注册时账号类型选**组织 (Organization)** —— 选定后不可改; 组织
   账号豁免个人账号「12 名测试员封闭测试 14 天」的发布前置;
4. 支付 **25 美元一次性注册费** (无年费, 不退);
5. 完成身份验证 (证件 + 组织文件 + 邓白氏编码) 与开发者邮箱 / 电话
   动态密码验证, 通常数小时~2 个工作日出结果;
6. 售卖付费商品 (订阅) 需另建 Google Payments **商家资料**并配置
   收款账户【以官网为准】(商品配置与沙盒验收见
   [PLAY_BILLING_SANDBOX_QA.md](PLAY_BILLING_SANDBOX_QA.md), 依赖本账号)。

### 6.2 启动批次 (按外部周期倒排, 不做日历排期)

| 批次 | 触发条件 | 同批并行启动 |
| --- | --- | --- |

| 第 3 批 | 软著证书 + 备案号 + 隐私 URL + 账号全就位 | 各商店资质上传与提审 ([CHINA_STORE_COMPLIANCE.md](CHINA_STORE_COMPLIANCE.md) §8; 提审包侧前置见 [V1_LAUNCH_CHECKLIST.md](V1_LAUNCH_CHECKLIST.md) §10 放行规则) |

### 6.3 外部周期汇总 (办理机构侧, 全部【以官网为准】)

| 事项 | 机构侧周期 | 24 小时级动作提醒 |
| --- | --- | --- |
| 软著普通件 | 受理起 60 日内审查 (约 30~40 个工作日); 加急数个工作日~数周 | 补正通知 30 日内响应 |
| 邓白氏编码 | 最长约 30 天 | — |
| 网站 / App 备案 | 服务商初审 1~2 个工作日 + 管局最长约 20 个工作日 (全程约 3~22 个工作日) | 工信部核验短信 **24 小时内**完成; 初审电话保持畅通 |
| 华为企业认证 | 打款 30 分钟~3 个工作日; 人工审核 1~2 个工作日 | 打款到账后及时回填金额与随机码 |
| 应用宝企业认证 | 数个工作日 | 对公账户盯流水回填随机金额 |
| Google Play 开户 | 验证数小时~2 个工作日 (不含邓白氏) | — |
| Microsoft / Apple | 公司验证数个工作日 | — |
| 公安联网备案 | — | 网站 / App 开通后 **30 日内**提交 |

**关键路径 = 软著**: 其余事项都能在软著审查期内并行走完; 软著证书
到手时若备案号与隐私 URL 已就位, 即可直接进入第 3 批。
