# MagTile Studio · 商用安全与隐私规范 (Security & Privacy Spec)

> 本文是 MagTile Studio 作为**面向 4–12 岁儿童的商用软件**的安全与隐私唯一规范。任何功能（尤其是账号、支付、网络、内容更新）在设计与合入前必须对照本文逐条过关。

>

## 1. 安全设计总原则

| # | 原则 | 说明 |
|---|------|------|
| S1 | **数据最小化** | 能不采就不采。默认零账号可用；本地进度即全部用户数据 |
| S2 | **儿童零 PII** | 任何版本、任何渠道的儿童侧界面不采集、不传输儿童个人身份信息 |
| S3 | **家长控制** | 支付/设置/外链/账号/数据操作全部置于家长门之后 |
| S4 | **默认安全** | 离线优先（无网络 = 无攻击面）；网络功能逐项显式启用，全部 TLS |
| S5 | **内容即数据不即代码** | 模型 JSON 是纯数据，永不作为代码执行；解析前 schema 校验 |
| S6 | **可验证的更新链** | 应用与内容更新只接受签名验证通过的包 |
| S7 | **透明可审计** | 隐私政策写人话；家长可查看/导出/删除全部数据 |

## 2. 威胁模型（儿童应用专项）

### 2.1 资产清单

| 资产 | 敏感度 | 位置 |
|------|--------|------|
| 儿童搭建进度/成就/游玩时长 | 低（无 PII，但属儿童行为数据） | 本地 `progress.db` |
| 磁力片库存（家庭财产线索，弱敏感） | 低 | 本地 `progress.db`（`tile_inventory` 表） |
| 家长门 PIN | 中 | 本地（加盐哈希） |
| 家长账号凭证（M4 云同步起） | 高 | 服务端 + 本地令牌 |
| 支付凭据 | 高 | **不经手**——全部由平台 IAP 处理 |
| 模型内容库（商业资产） | 中 | 应用包 + CDN |
| 更新通道 | 高 | 签名体系 |

### 2.2 威胁分析（STRIDE × 儿童场景）

| 威胁 | 场景 | 缓解措施 | 状态 |
|------|------|----------|------|
| **儿童误操作支付** | 孩子点到订阅按钮完成扣费 → 家长投诉/退款/差评/监管风险 | 家长门强制关卡（§6）+ 儿童侧不显示价格 + 平台 IAP 二次验证 | `PLANNED`（M3 前置） |
| **诱导泄露信息** | 界面诱导儿童输入姓名/照片/位置 | 产品层面**不存在**任何儿童侧输入个人信息的界面（S2 红线） | `POLICY`（现状即合规：当前代码零采集） |
| **恶意内容注入** | 篡改/伪造模型 JSON 导致崩溃、越权读写或 UI 欺骗 | JSON schema 严格校验 + 解析器健壮性 + 内容签名（§7） | `IN_PROGRESS` |
| **中间人攻击 (MITM)** | 公共 Wi-Fi 下劫持内容更新/订阅校验 | 全量 TLS 1.2+ + API 证书锁定（§8） | `PLANNED`（当前无网络功能，攻击面为零） |
| **供应链投毒** | 第三方库/更新包被植入恶意代码 | 依赖清单极简（SQLite 内嵌自编译）+ 更新包签名（§9）+ 依赖审计 | `IN_PROGRESS` |
| **本地数据窃取** | 共享/失窃设备上读取进度库 | 数据本身无 PII（损害有限）+ 可选静态加密（§5.3） | `IN_PROGRESS`（最小化 DONE，加密 PLANNED） |
| **家长门绕过** | 孩子暴力尝试算术题/偷看 PIN | 3 次错误冷却 60s + PIN 加盐哈希 + 题目随机化 + 中文大写数字输入 | `IN_PROGRESS`（冷却/随机化/中文大写数字 stub `DONE`；PIN `PLANNED`） |
| **越权数据上报** | 引入的 SDK 偷偷采集设备信息 | 儿童构建零第三方分析 SDK（§5.2）+ 发布前网络流量审计（§11） | `POLICY` + `PLANNED`（审计流程） |
| **不当内容出现** | UGC 阶段（M5）用户模型含不当命名/形状 | UGC 上线前置审核管线；M5 前无 UGC 通道 | `PLANNED`（M5） |
| **拒绝服务/崩溃** | 畸形 JSON、超大模型使应用崩溃吓到孩子 | 解析上限（片数/步数/文件大小）+ 负例测试 | `IN_PROGRESS`（负例测试 DONE，硬上限 PLANNED） |

### 2.3 明确不在威胁模型内

- 设备已 root/越狱后的本地作弊（改进度、解锁内容）：损害仅限本机体验，不做强对抗，订阅校验以服务端为准（M4+）。
- 家长自愿导出数据后的二次泄露。

## 3. 数据采集清单（最小化承诺）

### 3.1 我们采集什么（全量列表，超出即违规）

| 数据 | 内容 | 存储 | 传输 | 状态 |
|------|------|------|------|------|
| 搭建进度 | model_id、当前步、完成时刻、累计游玩秒 | 本地 SQLite | M4 云同步起可选上传（家长开启） | `DONE`（本地） |
| 成就 | 成就 id + 首次解锁时刻 | 本地 SQLite | 同上 | `DONE`（本地） |
| 收藏/设置 | 收藏标记、音量、字号、年龄段模式等 | 本地 SQLite | 不传输 | `DONE`（存储层） |
| 磁力片库存 | 片型 → 数量 | 本地 SQLite（`tile_inventory` 表） | 不传输 | `DONE`（存储层 + CLI 录入） |
| 家长账号（仅 M4+，可选） | 家长邮箱/第三方 OAuth 标识 | 服务端 | TLS | `PLANNED` |
| 订阅凭证 | 平台 IAP 收据/本地宽限凭证 | 本地 + 平台 | 平台通道 | `PLANNED` |
| 崩溃诊断（仅家长明示同意后） | 脱敏堆栈，不含用户数据 | 自建服务 | TLS | `PLANNED` |

### 3.2 我们**永不**采集（红线，`POLICY`）

- 儿童姓名、生日、照片、语音、视频、通讯录、位置（含粗略位置）。
- 设备广告标识符（IDFA/GAID）——代码中禁止出现相关 API 调用。
- 儿童侧任何自由文本输入（产品上根本不设输入框）。
- 行为画像/跨应用追踪数据。

> **「年龄段模式」说明**：4–6/7–9/10–12 三档模式由家长选择，仅作为本地 UI 开关存储，不与任何标识符关联、不上传——不构成儿童个人信息处理。

## 5. 客户端数据与构建安全

### 5.1 本地数据

- 进度库为单文件 SQLite（`progress.db`），schema 版本化（`PRAGMA user_version`），旧应用拒写新版本库，防降级损坏。`DONE`
- 数据库路径由平台外壳注入应用私有目录（Android `filesDir`、Windows `%APPDATA%`），不落公共存储。`DONE`
- Android 构建关闭 `allowBackup` 的云备份白名单外泄（backup 规则仅含 progress.db，且 M4 起若含令牌则排除令牌文件）。`PLANNED`

### 5.2 儿童构建零第三方分析 SDK（`POLICY`，验收硬条款）

- 儿童可达的应用构建中**禁止**集成：第三方统计/分析（含友盟、Firebase Analytics、AppsFlyer 等）、广告 SDK、第三方推送、社交分享 SDK、第三方登录 SDK（家长登录用系统级 Sign in with Apple / 微信仅在家长区且 M4+ 评估）。
- 崩溃收集若引入，只允许**自建或可自托管**方案（如 self-hosted Sentry），默认关闭，家长在家长区明示开启，上报内容脱敏（无设备标识符、无用户数据）。`PLANNED`
- CI 增加依赖清单检查：构建产物中出现黑名单 SDK 符号即失败。`PLANNED`
- 当前状态佐证：代码依赖仅 SQLite（内嵌自编译）+ 系统 OpenGL，**零网络代码、零第三方服务**。`DONE`（现状）

### 5.3 静态加密（Encryption at Rest）

- **现阶段决策**：进度数据不含 PII，明文 SQLite 可接受（与 PLATFORM_ARCHITECTURE §5.1 一致），密钥管理复杂度 > 收益。`DONE`（决策记录）
- **预留升级路径**：`ProgressStore` 独占单连接的设计可平滑替换为 **SQLCipher**（SQLite 加密分支，AES-256）。触发条件（任一满足即升级）：① 库中开始存储家长账号令牌/邮箱；② 进入对静态加密有硬性要求的渠道（部分 B 端/教育局采购）；③ Z5 评估要求。密钥存平台安全设施（Android Keystore / Windows DPAPI / macOS Keychain）。`PLANNED`（条件触发）
- 家长门 PIN：永不明文存储，`PBKDF2-HMAC-SHA256`（≥ 100k 迭代）加盐哈希后存 settings。`PLANNED`
- M4 起的账号令牌：只存平台安全存储（Keystore/DPAPI/Keychain），不进 SQLite。`PLANNED`

## 6. 家长门（安全侧要求）

交互规范见 [UI_UX_SPEC.md](UI_UX_SPEC.md) §9；本节为安全硬性要求。状态：`IN_PROGRESS`（算术题门 stub `DONE`，已在桌面 GL 版 `library --gui` 与 Qt 版 `magtile_studio_qt` 拦截家长区入口——两版共用同一 `core::ParentGate` 状态机，Qt 版门后含设置页与订阅占位页，且会话到期/锁定时自动退出家长区，见 UI_UX_SPEC §9.0；PIN 与家长中心完整覆盖为 M3 商用前置）。

### 6.1 必须置于家长门之后的操作（全量列表）

| 操作 | 说明 |
|------|------|
| **一切付费入口** | 订阅页、内容包购买、恢复购买 |
| **设置（完整版）** | 年龄段切换、主题语言、数据操作 |
| **外部链接** | 隐私政策在线版、客服、应用评分、官网——儿童侧无任何可点出应用的路径 |
| **账号操作**（M4+） | 注册/登录/登出/注销、云同步开关 |
| **数据操作** | 进度重置、数据导出、数据清除 |
| **诊断开关** | 崩溃上报开启/关闭 |

### 6.2 实现要求

- 门验证结果**只在内存中保留一个家长会话**，不落盘「已通过」标记，防重启绕过。`DONE`（stub 会话时长 15 分钟，`core::ParentGate` 构造可配置；「离开家长区即失效」的收紧策略为 M3 校准项，当前提供「锁定家长区」按钮手动结束会话）
- 算术题随机生成，答案要求中文大写数字输入（「陆拾叁」），显著提高学龄儿童通过难度。`DONE`（乘法题 + 中文大写数字软键盘）
- 连续 3 次错误 → 60 秒冷却，冷却计时存内存（重启绕过冷却可接受——门的目标是拦儿童，不是拦成人攻击者）。`DONE`
- 可选 4 位 PIN：§5.3 哈希存储；忘记 PIN 的兜底是算术题门 + 二次确认，不设「找回问题」（避免多余数据）。`PLANNED`
- 家长门组件做成独立可复用模块并单元测试（题目生成域、验证逻辑、冷却状态机）。`DONE`（`core::ParentGate` + ctest `parent_gate`）

## 7. 内容安全：模型 JSON 校验

模型内容（`data/models/*.json`、`tile_catalog.json`、库存 JSON）是应用**唯一的外部数据输入面**。原则 S5：**内容是数据，永不是代码**。

| 措施 | 说明 | 状态 |
|------|------|------|
| 纯数据格式 | JSON 中无任何脚本/表达式/路径字段；解析后只映射为强类型 C++ 结构体（`ModelDefinition` 等），无动态求值 | `DONE`（架构性保证） |
| 结构校验 | 解析时校验必填字段、类型、枚举合法性，失败给中文错误并拒载 | `DONE`（json_io + 错误路径） |
| 语义校验 | 步骤连续性/引用存在性/无重复/全覆盖（`TutorialEngine::checkConsistency`）+ 物理规则 R1–R8（`PhysicsValidator`），不合法内容进不了内容库 | `DONE` |
| 负例测试 | 悬空/重叠/不可放置等畸形模型必须校验失败（`tests/test_physics_negative/`） | `DONE` |
| 资源上限 | 解析硬上限：单文件 ≤ 2MB、片数 ≤ 2000、步数 ≤ 500、字符串字段 ≤ 512 字符；超限拒载防 DoS | `PLANNED` |
| 字符串处理 | 模型名称/说明按纯文本渲染（QML/Compose 文本组件），永不作为富文本/HTML/格式串解释；文件名白名单 `[a-z0-9_]`，路径拼接用安全 API 防目录穿越 | `IN_PROGRESS`（现纯文本渲染 DONE；白名单校验 PLANNED） |
| 内容包签名 | CDN 分发的内容包（M4）附 Ed25519 签名，客户端内置公钥验签后才解包入库；解包路径限制在内容目录内 | `PLANNED` |
| 模糊测试 | JSON 解析器 fuzz（libFuzzer，畸形输入不崩溃）纳入 CI 周任务 | `PLANNED` |

## 8. 网络安全

**现状**：应用零网络代码（离线完整可用），网络攻击面为零。`DONE`（现状）。以下规范自 M3（订阅校验）/M4（云同步、CDN）网络功能引入时强制生效。

| 措施 | 说明 | 状态 |
|------|------|------|
| 仅 TLS | 全部连接 TLS 1.2+（推荐 1.3）；**禁止**任何明文 HTTP，Android 声明 `usesCleartextTraffic=false`，iOS 不豁免 ATS，桌面端 HTTP 客户端禁用明文 scheme | `PLANNED` |
| **证书锁定（Certificate Pinning）** | 自有 API 域名（订阅校验/云同步/崩溃上报）锁定叶证书 SPKI 哈希，内置主备两枚 pin 支持轮换；锁定失败 → 功能降级为离线模式并静默告警，**不弹吓人错误给孩子** | `PLANNED` |
| CDN 例外策略 | 内容 CDN 域名不强制 pinning（CDN 证书轮换频繁），改由 §7 内容包签名保证完整性——传输被劫持也无法伪造内容 | `PLANNED`（设计已定） |
| 最小 API 面 | 客户端只调用自有 API：订阅凭证校验、内容清单、内容包下载、（可选）云同步、（可选）崩溃上报;无任何第三方域名 | `POLICY` |
| 请求最小化 | 请求头不带设备标识符;必要的防重放用随机 nonce 而非设备 ID | `PLANNED` |
| 服务端校验为准 | 订阅有效性以服务端签发的短期凭证为准，本地只存宽限凭证（7 天），防本地篡改无限续期 | `PLANNED` |
| 密钥管理 | 客户端不内置任何 API secret（公钥除外）;服务端密钥走 KMS，轮换季度化 | `PLANNED`（服务端 M4） |

## 10. 事件响应计划（Incident Response）

商用发布（M3）前建立;含儿童数据的合规通报义务见 §4 Z7。状态：`PLANNED`。

### 10.1 分级

| 级别 | 定义 | 示例 | 响应时限 |
|------|------|------|----------|
| **P0** | 儿童数据泄露/更新通道沦陷/支付安全事件 | 云端进度库被拖、签名私钥泄露 | 1 小时内启动作战室 |
| **P1** | 可远程利用的客户端漏洞 | JSON 解析 RCE、家长门可被程序化绕过 | 24 小时内热修/下架决策 |
| **P2** | 本地漏洞/合规瑕疵 | PIN 哈希实现缺陷、隐私文案缺漏 | 下一发布周期修复 |
| **P3** | 无实际影响的加固项 | 依赖库 CVE 但不可达 | 纳入 backlog |

### 10.2 响应流程（P0/P1）

```
发现/接报 → 1h 内定级与作战室（技术负责人+儿童信息保护专员+运营）
  → 遏制（吊销密钥/下线接口/商店提审热修/必要时暂停云同步）
  → 评估影响范围（哪些用户、哪些数据、什么时间窗）
  → 通报：
      · 涉儿童个人信息 → 按《规定》告知监护人 + 报网信部门；按 COPPA/FTC 要求评估美区义务
      · 应用商店安全事件 → 同步 Apple/Google 安全团队
  → 修复发布 → 复盘（5 Why + 规范修订，7 日内归档）
```

### 10.3 常备设施

- 安全联系渠道：`security@` 邮箱 + 商店页联系方式，承诺 48h 内响应外部报告。
- 密钥吊销预案：更新公钥/pin 均预埋备份，客户端无需强更即可切换。
- 数据处理活动记录（RoPA）常态维护，事件时可立即回答「我们有什么数据」。
