# 物理校验规则 (Physics Rules)

本文档精确定义 MagTile Studio 对模型与教程步骤执行的物理校验规则。实现位于 `src/physics/physics_validator.cpp`, 参数集中在 `PhysicsConfig`。

## 0. 校验范围与目标

物理校验的目标不是精确的刚体仿真, 而是回答一个商业问题: **用户照着教程搭, 每一步都能搭得起来、放得稳吗?**

规则分三组:

- **几何/拓扑规则 R1~R4**: 结构是否连通、贴合、不穿插、不倾倒;
- **静力学/工艺规则 R5~R8**: 每条磁力连接是否真的撑得住 (磁吸边是铰链不是刚性节点), 以及每一片按教程顺序放置时是否放得进去;
- **蒙特卡洛容差抖动 R9** (按需开启, `--jitter`): 注入毫米级随机放置误差后 R1~R8 是否依然全部成立 —— 验证金字塔 L2 层的静态近似档 (见 3 节末尾)。

校验器对以下对象逐一执行全部静态规则 (R1~R6、R8):

1. 最终成品 (`final_assembly` 全集);
2. **每一个教程步骤完成后的中间状态** (第 1 步完成后、第 2 步完成后、……)。

R7 (装配可达) 则按教程步骤与步骤内 `tiles_to_add` 的先后顺序**逐片**模拟放置。

任何一条 Error 级问题都会使模型质检失败 (`magtile_app validate` 返回非零), 不允许进入发布内容库。Warning 不阻断发布, 但须逐条评审 (见 `BUILD_VERIFICATION.md` 第 5 节)。

## 1. 术语与参数

长度单位与世界坐标一致 (1.0 = 正方形边长, 实物约 70mm); 质量单位为克, 按面积折算。

### 1.1 几何容差 (R1~R4)

| 参数 (PhysicsConfig) | 默认值 | 含义 |
| --- | --- | --- |
| `connect_tolerance` | 0.02 | 磁力边端点吸合容差 (0.02 单位 ≈ 1.4mm 实物) |
| `ground_tolerance` | 0.02 | 顶点视为"接触地面"的最大高度 |
| `overlap_tolerance` | 0.02 | 判定重叠所需的最小穿插深度 (排除共享边的相邻片) |
| `coplanar_tolerance` | 0.02 | 共面判定: 两平面间距上限 |
| `stability_margin` | 0.15 | 重心水平投影允许超出接地凸包的距离 (磁吸提供的裕量) |

### 1.2 静力学参数 (R5/R6)

| 参数 | 默认值 | 含义与取值依据 |
| --- | --- | --- |
| `tile_mass_per_area` | 30.0 | 面密度 g/单位面积 (正方形 1×1 实测约 30g) |
| `hanging_capacity_per_edge` | 150.0 | 单位长度磁力边的额定悬挂承重 (克)。实测一条标准边竖直悬挂约在 5 片正方形 (150g) 时脱落 |
| `hinge_moment_capacity_per_edge` | 25.0 | 单位长度磁力边的额定抗弯矩 (g·单位)。实测单片正方形平挑墙顶 (力矩 30g×0.5=15) 勉强稳住, 两片连挑 (力矩 60) 必掉, 取 25 |
| `knock_safety_factor` | 0.8 | 抗震/碰撞安全系数: 只允许用到额定承载的 80%, 保留 20% 抗碰撞裕量 |
| `max_hanging_tiles_per_edge` | 4 | 单条铰链边悬挂链片数上限, 超出仅 Warning (逐级铰链累积晃动) |
| `hanging_z_tolerance` | 0.1 | 悬挂判定: 子结构重心须低于铰链线至少此距离才算"受拉" |
| `collinear_tolerance` | 0.02 | 磁力边共线分组容差 (共线边合成一条铰链线) |

### 1.3 结构冗余参数 (R8)

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `tall_structure_height` | 2.5 | 最高点达到此高度即视为高层结构, 启用 R8 |
| `spof_min_component_tiles` | 3 | 单点失效警告阈值: 单条连接独自支撑的最少片数 |
| `unbraced_wall_max_height` | 4.0 | 无环 (纯树状) 结构允许的最大高度: 高于此且没有任何三角桁架/闭合环 → Error `unbraced_wall_too_tall` |

- **磁力边**: 形状目录中 `magnet_edges` 列出的边 (例如扇形的弧边不是磁力边)。
- **镂空/窗格片** (门框方 `door_frame` / 窗格方 `window_square`): 物理校验一律使用形状目录登记的**外框多边形** (与正方形完全一致) —— R1~R8 的边磁力逻辑、共面 SAT 重叠检测均按实心外框执行。`hollow` / `variant` 只是给教程文案、BOM 与渲染用的语义标记, 不参与任何物理判定; 若未来引入体积/封闭空间类检查, 镂空内部不得按实心遮挡处理 (见 `docs/TILE_SET.md`)。
- **接地片**: 存在顶点满足 `z ≤ ground_tolerance` 的磁力片。
- **铰链线**: 位于同一条空间直线上的一组磁力连接。磁吸边连接在实物上是"铰链": 抗压强 (下方有支撑时稳), 抗拉与抗弯都弱, R5/R6 正是对这两个弱项做预算校验。

### 1.4 参数档位 (`--profile`)

同一套规则可以在不同的参数档位下执行, 校验 CLI 通过 `--profile` 选择:

```
magtile_app validate <model.json> --profile strict
```

| 档位 | `hanging_capacity_per_edge` | `knock_safety_factor` | 有效悬挂预算 | 有效抗弯预算 | 定位 |
| --- | --- | --- | --- | --- | --- |
| `default` | 150 | 0.8 | 120g/单位边长 (≈4 片正方形) | 20 g·单位 | 官方基准品牌实测标定, **全部模型入库必过** |
| `strict` (`strict_consumer`) | 120 | 0.7 | 84g/单位边长 (≈2.8 片正方形) | 17.5 g·单位 | 弱磁品牌 / 磁力衰减旧片 / 加大抗碰撞余量 |

`strict` 档模拟两类真实世界的削弱, 消费者手里的磁力片远比实验室的新片脆弱:

1. **品牌差异**: 不同品牌的整边拉脱力差异显著 (磁铁数量、磁条布局、边缘倒角都不同), 弱磁品牌的额定承重按 120g/单位边长标定;
2. **磁力衰减与使用损耗**: 使用数年的旧片、被摔过的片, 磁力普遍下降; 同时儿童实际使用中的碰撞频率远高于成人测试, 安全系数从 0.8 收紧到 0.7。

配套纪律: **旗舰模型必须在 `strict` 档下依然全绿** —— CMake 注册了 `validate_strict_castle_foundation_01` / `validate_strict_eiffel_tower_01` / `validate_strict_tokyo_tower_01` 回归用例, 任何一条失败 CI 即红。全库模型当前在 `strict` 档下已验证全绿; 新模型若只过 `default` 不过 `strict`, 说明它贴着预算上限设计, 应按第 5 节"宁严勿松"原则加固而不是放过。

## 2. 几何/拓扑规则 (R1~R4)

### R1 接地支撑 (floating_tile)

> 每片磁力片必须存在一条经由磁力连接到达地面的支撑路径; 只有接地层磁力片可以直接接触地面。

判定: 以全部接地片为起点, 在磁力连接图 (见 R2) 上做广度优先搜索; 任何不可达的磁力片报 Error `floating_tile` ("悬空")。

这是"禁止悬空"的图论化表述: 允许力沿磁吸边传递 (立墙上再立墙、墙顶挂城齿都合法), 但空中孤片、只靠"视觉贴近"而没有磁力边贴合的片都会被判悬空。

**R1 前置: 禁止穿入地面 (below_ground_tile)**。桌面是刚体, 任何顶点低于地面 (`z < -ground_tolerance`) 的磁力片实物上根本摆不出来, 报 Error `below_ground_tile`。2026-08 负例回归加强时发现历史版本的漏洞: 接地判定把 `z ≤ ground_tolerance` 的顶点一律视为接触地面, 穿地片反而被当作稳定接地片放行 —— 已按第 5/6 节的回填闭环修复, 负例夹具 `tests/test_physics_negative/below_ground_tile.json` 锁定该回归。

### R2 磁力连接 (isolated_tile / disconnected_assembly)

> 相邻磁力片必须通过磁力边**完整贴合**吸附: 等长整边贴合, 或较短磁力边**完整**落在较长磁力边上。

判定: 两条磁力边视为吸合, 当且仅当**较短边的两个端点都落在较长边线段上** (点到线段距离 ≤ `connect_tolerance`)。由此得到磁力连接图:

- 多片模型中存在零连接的磁力片 → Error `isolated_tile`;
- 连接图不连通但各部分均接地 → Warning `disconnected_assembly` (物理上成立, 但要求内容制作者在教程中明确分组说明)。

两条边**等长**时, "短边被长边完整包含"退化为端点两两重合 (正序或反序), 与历史判定完全一致。**长短边搭配**是大正方形 (边长 2) 入库后的扩展: 一条长 2 的磁力边可以吸一条等长的边 (长方形长边、另一片大正方形的边、梯形下底), 也可以**同时吸两片共线的边长 1 磁力片**——各记一条独立连接, 两条连接共线时归入同一条铰链线参与 R5/R6 静力分析; 每条连接的承重/力矩预算按实际磁条接触段 (即短边) 长度累计, 不按长边名义长度虚增。短边全程磁条对磁条接触, 与整边贴合同样稳固。

**错位半搭仍判为未连接**: 短边任一端点悬出长边之外 (两片小方错位半格、小方半边悬出长方形长边等), 悬出部分没有磁条对齐, 实物上是不稳定的 (负例夹具 `tests/test_physics_negative/isolated_tile.json` 即错位半搭)。

### R3 无重叠 (tile_overlap)

> 任意两片磁力片不得互相穿插。

判定: 仅对**共面**的片 (法向平行且平面间距 ≤ `coplanar_tolerance`) 执行, 将两多边形投影到公共平面后做**分离轴检测 (SAT)**: 所有候选轴上的重叠深度都超过 `overlap_tolerance` 才判为重叠 → Error `tile_overlap`。

共享一条边的相邻片在该边法向轴上的重叠深度为 0, 因而不会误报; 不共面的片 (如地台与立墙) 天然不参与本规则。

第一阶段的形状全部是平面凸多边形, 共面 SAT 已覆盖实际穿模场景 (同层重铺、立墙插入地台等); 非共面斜穿的情形留待规则演进 (见第 8 节)。

### R4 重心稳定 (unstable_center_of_mass / no_ground_contact)

> 整体重心的水平投影必须落在接地区域内 (基础版)。

判定 (磁力片厚度、密度一致, 重量 ∝ 面积):

1. 重心 `COM = Σ(质心ᵢ · 面积ᵢ) / Σ面积ᵢ`;
2. 接地区域 = 全部满足 `z ≤ ground_tolerance` 的顶点在水平面上的**凸包** (Andrew 单调链);
3. `COM` 的水平投影到凸包的带符号距离 > `stability_margin` → Error `unstable_center_of_mass`;
4. 不存在任何接地顶点 → Error `no_ground_contact`。

`stability_margin` 表达磁吸提供的抗倾覆裕量: 单面立墙的接地区域退化为一条线段, 理想刚体下重心恰在线上属于临界平衡, 但实物磁力片靠底边磁吸完全立得住, 因此允许 0.15 单位的超出量。悬臂式外挑结构 (重心明显越过支撑边) 由 R4 与 R6 双重把守。

## 3. 静力学/工艺规则 (R5~R8) 与蒙特卡洛抖动 (R9)

R1~R4 只回答"结构是否连通且不倾倒", 却把每条磁力连接当成无限强——这正是"校验通过但实搭时掉下来"的根源。R5/R6 用**铰链切割静力分析**补上这一课。

**分析方法** (R5/R6 共用): 把所有共线的磁力连接归并为一条**铰链线**, 逐条假想剪断; 剪断后与地面失联的每个子结构, 其全部重量必须经由这条铰链传递:

- 子结构重心低于铰链线 (差距 > `hanging_z_tolerance`) ⇒ **悬挂**, 磁条受拉, 校验 R5 承重预算;
- 重力绕铰链轴产生的力矩 ⇒ **悬臂**, 磁条受弯, 校验 R6 力矩预算。

被三角斜撑 / 环状结构加固的部分, 剪断单条铰链线后仍有其他支撑路径, 自然不会成为失联子结构——**桁架的加固效果由图论连通性隐式表达**, 无需显式豁免规则。

前置条件: R1 通过且存在接地片 (悬空结构做静力分析没有意义)。

### R5 悬挂承重 (hanging_chain_overload / hanging_chain_long)

> 经由单条铰链线悬挂的磁力片总重, 不得超过该铰链线的承重预算。

判定 (对每条铰链线、每个剪断后失联且重心低于铰链线的子结构):

1. 子结构质量 = Σ(面积ᵢ × `tile_mass_per_area`);
2. 承重预算 = `hanging_capacity_per_edge` × 跨越铰链线的磁力边总长 × `knock_safety_factor` (默认 150 × 长度 × 0.8 = 120g/单位边长, **约合每条标准边 4 片正方形**);
3. 质量 > 预算 → Error `hanging_chain_overload` ("实搭时整串会脱落");
4. 质量未超, 但子结构片数 > `max_hanging_tiles_per_edge` × 跨越边数 → Warning `hanging_chain_long`: 铰链节点逐级累积晃动, 轻碰易整串脱落, 建议单边悬挂不超过 4 片。

### R6 悬臂力矩 (cantilever_overload)

> 单边连接是铰链而非刚性节点, 悬挑结构绕铰链轴的重力力矩不得超过抗弯预算。三角斜撑 / 外挑远端加支撑可豁免 (通过增加支撑路径自然豁免)。

判定 (对每条铰链线、每个剪断后失联的子结构):

1. 力矩 = |Σ mᵢ · ((质心ᵢ − 铰链点) × ĝ) · 铰链方向|, 即重力绕铰链轴的合力矩。正上/正下方的子结构力矩为零 (纯压/纯拉), 水平外挑越远力矩越大;
2. 抗弯预算 = `hinge_moment_capacity_per_edge` × 铰链线上磁力边总长 × `knock_safety_factor` (默认 25 × 长度 × 0.8 = 20 g·单位/单位边长);
3. 力矩 > 预算 → Error `cantilever_overload`, 提示"请添加三角斜撑或在外挑远端增加支撑"。

标定示例 (正方形 30g): 单片平挑墙顶力矩 = 30 × 0.5 = 15 < 20 → 放行 (实物确实勉强稳住); 两片连挑力矩 = 30×0.5 + 30×1.5 = 60 > 20 → 拒绝 (实物必掉)。

### R7 装配可达 (unplaceable_tile / enclosed_placement)

> 按教程顺序逐片放置时, 每片在放下的那一刻必须有依托, 且放置点必须从外部伸手可达。

静态规则保证每个中间状态"放好之后是稳的", R7 回答"这一片当时放得进去吗"。按教程步骤与步骤内 `tiles_to_add` 列表顺序逐片模拟, 与真人搭建顺序完全一致:

- **R7a 放下瞬间必须有依托**: 既不接地 (`ground_tolerance`)、又吸不到任何已放置磁力片 (`connect_tolerance`) → Error `unplaceable_tile`, 松手即掉。常见于步骤内 `tiles_to_add` 顺序写反 (先列了上层片)。
- **R7b 放置点必须从外部可达**: 从新片质心向正上、水平四向、水平对角四向、斜上四向共 **13 个方向**发射射线, 全部被已放置磁力片挡住 → Error `enclosed_placement` (封闭腔体内部, 手和磁力片都伸不进去)。不检测正下方 (桌面本来就挡)。常见于"先封顶再补内部隔断"的教程。

### R8 结构冗余 (single_point_of_failure / no_structural_redundancy / unbraced_wall_too_tall)

> 高层结构 (最高点 ≥ `tall_structure_height`) 中, 警告单点失效连接与纯树状拓扑; 纯树状结构超过 `unbraced_wall_max_height` 升级为 Error, 一票否决。

结构越高, 碰撞与桌面震动的放大效应越强; "被小朋友撞一下"无法静态精确建模, 因此按拓扑分级把守:

1. **单点失效**: 逐条剪断单条磁力连接, 若失联片数 ≥ `spof_min_component_tiles` → Warning `single_point_of_failure`: 掉一处塌一片, 建议增加三角桁架或第二条连接路径;
2. **无环拓扑**: 环路数 = E − (V − 连通分量数) 为零, 说明连接图纯树状, 没有任何三角桁架/闭合环, 每个节点都是自由铰链 → Warning `no_structural_redundancy`, 整体会像风铃一样晃;
3. **无桁架高墙错误级**: 连接图纯树状**且**最高点 ≥ `unbraced_wall_max_height` (默认 4.0, 实物约 28cm) → **Error** `unbraced_wall_too_tall`。逐层立墙叠到这个高度而没有任何三角斜撑、垂直翼墙或闭合圈层时, 每条水平缝都是自由铰链, 静力预算逐条全过 (纯压), 实物却轻碰即整面倒塌 —— 这类结构不允许发布, 不再只是提示。

已知边界 (诚实声明, 细化列入第 8 节演进路线): 本判定按**全局**环路数计算, 判不出"大底座有环、上方孤塔无环"的混合结构; 也判不出共面环 —— 平面网格墙内部的环只提供面内刚度, 出平面方向仍是自由铰链。

R8 警告的点位是实物验证 (`BUILD_VERIFICATION.md` 3.6.4) 中"误碰即塌"问题的第一修复参考。

### R9 蒙特卡洛容差抖动 (placement_jitter_failure, `--jitter`)

> 对每片放置注入随机误差 (平移每轴 ±0.021 单位 ≈ ±1.5mm、绕竖直轴偏航 ±2°) 后, 整套 R1~R8 (成品 + 每步中间态 + R7 逐片放置) 必须在全部 N 轮抖动副本 (默认 50) 下依然成立; 任一轮出现 Error → Error `placement_jitter_failure`。

这是验证金字塔 L2 层 (`BUILD_VERIFICATION.md` 第 1 节) 的静态近似档, 按需开启:

```
magtile_app validate <model.json> --jitter [N] [--profile strict]
```

儿童实搭时每片都放不到理想位置: 每步 0.5~2mm 的贴合误差单独看都在容差内, 十几步累积后却可能"对不上缝"或整体歪斜失稳 (`BUILD_VERIFICATION.md` 失效分类 F08) —— 这是 R1~R8 在理想几何上原理性算不了的失效模式, 此前只能靠 L3 实物复核 (三层中最贵的发现路径) 兜底。判定细节 (实现: `PhysicsValidator::validateModelWithJitter`, 接口约定见 `BUILD_VERIFICATION.md` 2.1 节):

1. **误差注入**: 每轮对模型每片独立注入水平平移 (x/y 每轴均匀 ±`translation_amplitude`, 默认 0.021 单位 ≈ 1.5mm) 与绕世界竖直轴的偏航 (均匀 ±`yaw_amplitude_deg`, 默认 2°), 整轮教程期间保持不变 —— 模拟"这一次搭建中每片都放歪了一点且没有回调"的误差累积场景 (每片在教程中恰好放置一次, 扰动成品即等价于扰动每步放置位置)。不注入竖直平移与俯仰/滚转: 桌面与下方结构的硬接触加上磁吸边的自动归位约束了这三个自由度, 扰动它们只会制造"穿地"类假阳性;
2. **连接识别不受注入误差干扰**: 贴合 (R2/R7a)、共面重叠 (R3)、铰链共线分组 (R5/R6) 的几何识别容差按注入误差的最坏情况放大 (2 × (平移幅度 × √2 + 最大片局部半径 × sin 偏航幅度)) —— 实物中毫米级错位会被磁吸自动拉回贴合, 效果上等价于"连接拓扑按未扰动模型取定", 不把刻意注入的错位误报成"没连上/穿插"。接地容差不放大 (注入的扰动不改变任何顶点的 z); **重心稳定裕量 (`stability_margin`) 与 R5/R6 静力预算保持所选档位原值不变** —— 它们正是抖动要考核的对象;
3. **判定阈值**: 任一轮、任一受测装配体出现 Error 即整体失败, 严于深潜文档最初"通过率 ≥ 90%"的最低口径 (第 5 节宁严勿松: 每 10 次搭建塌 1 次的模型不允许发布);
4. **确定性**: 固定随机种子 (`JitterConfig::seed`) + 自带均匀分布映射 (不依赖 `std::uniform_real_distribution` 的跨标准库实现差异), CI 逐轮可复现; 抖动负例夹具的单轮失败率按 ≥ 30% 设计, 结论对种子与轮数变化不敏感。

报告: 汇总为一条 `placement_jitter_failure` Error, 内含失败轮数/总轮数、涉及的底层错误码集合、首个失败样本的完整消息 (自带"最终成品/第 N 步"上下文) 与涉事片 id。执行顺序: 常规 R1~R8 未通过时跳过抖动仿真 (对静态已不成立的模型做抖动没有意义, CLI 打印提示)。

## 5. 参数标定与调参纪律 —— 宁严勿松

**"软件校验通过, 孩子却搭不起来 / 搭到一半塌了", 是整个产品最不可接受的失败。** 教程产品的全部价值建立在一个承诺上: 照着搭, 一定搭得起来。孩子搭到第 12 步塌一次, 挫败感直接终结这次搭建; 家长遇到两次, 对整个内容库失去信任。所以调参的最高纪律是**宁严勿松**:

- **误杀** (真实能搭成的模型被拒绝) 的代价, 是内容作者多花时间加固或调整设计;
- **误放** (明显会掉的结构被放行) 的代价, 由客厅里 4 岁的孩子承担。

两种错误的代价完全不对称, 冲突时永远选择前者: 通过修改模型 (加固) 而不是放宽参数来解决误杀。具体纪律:

1. R5/R6 的预算参数来自实物测量 (见 1.2 节表格中的取值依据), 并统一乘 `knock_safety_factor` 保留抗碰撞裕量; 面向弱磁品牌与旧片另设 `strict` 档 (见 1.4 节), 旗舰模型必须双档全绿;
2. 任何参数改动后, `tests/test_physics_negative/` 负例套件必须仍然按各夹具 `.expected` sidecar 声明的期望报错/报警 (error 级拒绝、warning 级报告, 见 `TESTING.md` 3.7 节), `tests/test_physics_positive/` 正例夹具与全库模型必须仍然通过 (`tests/test_all_models.sh`); 负例套件本身的完整性由 `physics_fixture_registry` 关卡把守, 缺夹具即 FAIL;
3. 实物验证 (见 `BUILD_VERIFICATION.md`) 中"软件放行但实搭失败"的案例, 一律**先回填为负例夹具**再修规则/收紧参数——用回归用例锁住每一次教训, 同类问题永不复发;
4. **放宽任何参数必须有实测证据** (`BUILD_VERIFICATION.md` 3.6.4: 校验器拒绝但目标年龄段儿童反复轻松搭成), 且放宽后全部负例夹具仍被拒绝; 没有实测证据的"看起来应该没问题"不构成放宽理由。

**大片型标定说明** (`large_square` 等边长 2 的片型): R5/R6 预算随磁力边**长度**线性增长, 质量却随**面积**平方增长 —— 大正方形一条边的承载预算是标准边的 2 倍, 自重却是标准片的 4 倍, 同样的悬挑/吊挂设计换成大片更容易超限。这不是需要特判的例外, 而是真实物理: 大片适合做地台与墙面主体 (受压), 不适合出现在悬挑远端或吊挂链上; 校验器按几何自然算出这一结论, 无需任何按片型的特殊豁免。

## 6. 人工复核工作流

自动校验的边界必须诚实声明: **R1~R8 全绿只代表"静力模型认为撑得住", 不等于实搭万无一失。** 以下失效模式只有真人拿真磁力片才能发现:

| 只有人能发现的问题 | 为什么校验器看不到 |
| --- | --- |
| **磁极方向不合** | 实物磁条是旋转磁极设计, 个别品牌/批次在特定拼角会互斥; 校验器假设"贴合即吸附" |
| **个体公差与磁力衰减** | 旧片磁力衰减、注塑飞边导致边缘不贴合; 校验器使用理想几何 |
| **操作空间与手感** | 某一步需要一只手同时扶住三处; R7 只判"伸得进去", 不判"单手拿得稳" |
| **放置瞬间的扰动** | 放第 N 片时手带倒第 N-1 片 (尤其立墙链); 静力分析只看放好之后的状态 |
| **桌面材质与微震** | 桌布、玻璃面、桌腿晃动改变接地摩擦与共振; 校验器假设理想硬质水平面 |
| **儿童行为差异** | 目标年龄段的手部力量与耐心与成人完全不同; 无法建模 |

因此执行以下分工 (完整规程与记录格式见 `BUILD_VERIFICATION.md`):

1. **全部模型**: R1~R8 自动校验是入库的必要条件 (L1), Error 一票否决;
2. **R8 Warning**: 不阻断发布, 但每条 Warning 必须由内容制作者书面确认"接受该风险"或加固后复验;
3. **难度 4+ (T4/T5) 模型**: 自动校验通过后**必须实物复核** —— 真人按教程逐步搭一遍, 执行敲击/提起/拆解重搭测试; `magtile_app validate` 对 difficulty ≥ 4 的模型会在结论前打印实物复核提示;
4. **回填闭环**: 实物复核发现"软件放行但实搭失败"的, 先回填负例夹具 (`tests/test_physics_negative/`), 再修规则/参数, 保证同类问题永不复发。

## 7. 与教程一致性检查的分工

物理规则之外, `TutorialEngine::checkConsistency` 负责纯数据层面的质检 (步骤序号连续、每片恰好放置一次、引用存在、说明非空)。`magtile_app validate` 同时执行两类检查, 全部通过才判定"可发布"。

## 8. 规则演进路线

已在本版落地的前路线项: 逐片力矩分析 (→ R6)、搭建顺序人因校验的可达性部分 (→ R7)、无环高墙错误级拦截 (→ R8 `unbraced_wall_too_tall`)、弱磁严格档 (→ `--profile strict`)、蒙特卡洛容差抖动 (→ R9 `--jitter`)。后续按内容库需要演进 (完整差距分析与加固优先级见 `PHYSICS_VERIFICATION_DEEP_DIVE.md`):

1. **多铰链连锁剥离 (multi-hinge peel)**: R6 目前逐条铰链线独立剪断分析, 挂在多条平行铰链上的子结构在"逐条剪"视角下可能条条合格, 实物却会从最弱一条开始逐级剥离连锁脱落; 需要扩展为组合切割集分析 (至少覆盖两条铰链线的组合);
2. **共面环与分支高度细化**: R8 的无环判定按全局环路数计算, 需细化为"出平面加固"判定 (共面环不算加固) 与按分支的局部高度分析 (大底座有环不能豁免上方的孤立高塔);
3. **非共面穿插检测**: 多边形对的 3D 相交测试, 覆盖斜插穿模;
4. **子结构稳定性**: 对每个连通子结构独立做重心检查 (当前对整体做);
5. **单手可放置校验**: R7 只判"伸得进去", 未判"单手拿稳一片的操作空间", 需要手部包围体模型;
6. **柔性接头模拟**: 磁吸片受压时的微小转动, 用于球面/穹顶类高难模型的可搭性预判;
7. **刚体仿真层**: 蒙特卡洛容差抖动已按静态近似档落地 (→ R9 `--jitter`); 剩余为动力学两段 —— 刚体引擎静置沉降与扰动脉冲测试 (磁吸边建模为按品牌标定的可断裂约束), 作为验证金字塔第 2 层的后续增强 (见 `BUILD_VERIFICATION.md` 第 1 节 / `PHYSICS_VERIFICATION_DEEP_DIVE.md` P1-3 剩余项), 捕捉静态重算近似不了的时域失稳。
