# 上架前安全与隐私三平台签核单 (Privacy & Security Sign-off)

- 对应清单项: [V1_LAUNCH_CHECKLIST.md](../V1_LAUNCH_CHECKLIST.md) §5 **V4**
  (P0, Manual) —— 「上架前跑一遍安全与隐私自查单 (三平台逐项)」的
  **可执行签核载体**。
- 逐项来源: [SECURITY_AND_PRIVACY.md](../SECURITY_AND_PRIVACY.md) 的合规
  检查清单 (§3 数据清单 / §4 COPPA+《规定》/ §5.2 零第三方 SDK /
  §6 家长门 / §8 网络现状 / §11 发布安全测试清单) —— 该文档定义
  「查什么、红线是什么」, 本表把它落成**按平台逐项勾选 + 签核归档**的
  工作单, 勾选判定与该文档冲突时以该文档为准。
- 对外承诺互证: 每组核对项标注 [PRIVACY_POLICY_DRAFT.md](../PRIVACY_POLICY_DRAFT.md)
  对应章节 —— 本表验证的就是「隐私政策怎么写, 出包产物就怎么做」;
  任一不符即为 P0 阻断 (要么改产物, 要么改政策并三处同步, 见
  SECURITY_AND_PRIVACY §12「审核一致性」)。
- 归档约定: 仓库内只保存**空白模板**。每次商店提审前复制本文件为
  `PRIVACY_SECURITY_SIGNOFF_<YYYY-MM-DD>.md`(或复制到 QA 工单) 填写,
  三平台可分人并行、各签各列; 完成后把 V4 行状态回填 ✅ 并挂归档链接。
  数据实践变更 (新增采集字段 / 引入网络功能 / 新增 SDK) 时**先改本表
  模板**再改代码, 与政策、商店表单三处同步。
- **严禁未实测勾选或事后补签** —— 本表结论将支撑商店「数据安全」表单
  申报, 伪造勾选等同于向商店与家长虚假陈述。

## 0. 使用方法 (执行人开工前读一遍)

1. **执行对象是候选出包产物, 不是开发档构建**: 计费/开发开关按构建
   配置分档 (桌面开发档 FakeBilling、Debug 档模拟订阅), 拿开发档跑
   本表会得出失真结论。产物口径见 §1 表。
2. **先跑自动侧再走人工项**: `tools/check_v1_readiness.sh --strict`
   输出全文附于工单 (含 R8 隐私文档存在性 / R16 儿童友好文案守卫 /
   R11·R11W 计费接线探测); 自动侧任一 P0 FAIL 时人工走查暂停。
3. **逐行勾选**: 每行按平台记 `✓ 通过` / `✗ 不通过` / `n-a 不适用`;
   不通过**当场**在「问题记录」列写 issue / 工单链接, 不许留白。
4. **放行判定** (与 V1_LAUNCH_CHECKLIST §0 同口径): 标 **P0** 的行任一
   平台不通过 → 该平台不出包; 标 **P1** 的行允许带已记录问题上架,
   但必须在 §9 签核栏留痕。
5. 执行时机建议与真机验收 (清单 D3/A4) 及断网复核 (V5) 同批安排 ——
   离线组与导出删除组的多数项本就要在真机/干净机上做。
