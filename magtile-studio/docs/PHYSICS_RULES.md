# 物理校验规则 (Physics Rules)

本文档精确定义 MagTile Studio 对模型与教程步骤执行的物理校验规则。实现位于 `src/physics/physics_validator.cpp`, 参数集中在 `PhysicsConfig`。

## 0. 校验范围与目标

物理校验的目标不是精确的刚体仿真, 而是回答一个商业问题: **用户照着教程搭, 每一步都能搭得起来、放得稳吗?**

因此校验器对以下对象逐一执行全部规则:

1. 最终成品 (`final_assembly` 全集);
2. **每一个教程步骤完成后的中间状态** (第 1 步完成后、第 2 步完成后、……)。

任何一条 Error 级问题都会使模型质检失败 (`magtile_app validate` 返回非零), 不允许进入发布内容库。

## 1. 术语与参数

| 参数 (PhysicsConfig) | 默认值 | 含义 |
| --- | --- | --- |
| `connect_tolerance` | 0.02 | 磁力边端点吸合容差 (0.02 单位 ≈ 1.4mm 实物) |
| `ground_tolerance` | 0.02 | 顶点视为"接触地面"的最大高度 |
| `overlap_tolerance` | 0.02 | 判定重叠所需的最小穿插深度 (排除共享边的相邻片) |
| `coplanar_tolerance` | 0.02 | 共面判定: 两平面间距上限 |
| `stability_margin` | 0.15 | 重心水平投影允许超出接地凸包的距离 (磁吸提供的裕量) |

- **磁力边**: 形状目录中 `magnet_edges` 列出的边 (例如扇形的弧边不是磁力边)。
- **接地片**: 存在顶点满足 `z ≤ ground_tolerance` 的磁力片。

## 2. 四大规则

### R1 接地支撑 (floating_tile)

> 每片磁力片必须存在一条经由磁力连接到达地面的支撑路径; 只有接地层磁力片可以直接接触地面。

判定: 以全部接地片为起点, 在磁力连接图 (见 R2) 上做广度优先搜索; 任何不可达的磁力片报 Error `floating_tile` ("悬空")。

这是"禁止悬空"的图论化表述: 允许力沿磁吸边传递 (立墙上再立墙、墙顶挂城齿都合法), 但空中孤片、只靠"视觉贴近"而没有磁力边贴合的片都会被判悬空。

### R2 磁力连接 (isolated_tile / disconnected_assembly)

> 相邻磁力片必须通过**等长磁力边完全贴合**吸附。

判定: 两条磁力边视为吸合, 当且仅当端点两两重合 (正序或反序), 距离容差 `connect_tolerance`。由此得到磁力连接图:

- 多片模型中存在零连接的磁力片 → Error `isolated_tile`;
- 连接图不连通但各部分均接地 → Warning `disconnected_assembly` (物理上成立, 但要求内容制作者在教程中明确分组说明)。

端点两两重合意味着两条边**等长且完全对齐**——这正是磁力片的真实吸附方式: 只有整边贴合时磁条才对齐, 半搭 (错位半格) 在实物上是不稳定的, 直接判为未连接。

### R3 无重叠 (tile_overlap)

> 任意两片磁力片不得互相穿插。

判定: 仅对**共面**的片 (法向平行且平面间距 ≤ `coplanar_tolerance`) 执行, 将两多边形投影到公共平面后做**分离轴检测 (SAT)**: 所有候选轴上的重叠深度都超过 `overlap_tolerance` 才判为重叠 → Error `tile_overlap`。

共享一条边的相邻片在该边法向轴上的重叠深度为 0, 因而不会误报; 不共面的片 (如地台与立墙) 天然不参与本规则。

第一阶段的形状全部是平面凸多边形, 共面 SAT 已覆盖实际穿模场景 (同层重铺、立墙插入地台等); 非共面斜穿的情形留待规则演进 (见第 5 节)。

### R4 重心稳定 (unstable_center_of_mass / no_ground_contact)

> 整体重心的水平投影必须落在接地区域内 (基础版)。

判定 (磁力片厚度、密度一致, 重量 ∝ 面积):

1. 重心 `COM = Σ(质心ᵢ · 面积ᵢ) / Σ面积ᵢ`;
2. 接地区域 = 全部满足 `z ≤ ground_tolerance` 的顶点在水平面上的**凸包** (Andrew 单调链);
3. `COM` 的水平投影到凸包的带符号距离 > `stability_margin` → Error `unstable_center_of_mass`;
4. 不存在任何接地顶点 → Error `no_ground_contact`。

`stability_margin` 表达磁吸提供的抗倾覆裕量: 单面立墙的接地区域退化为一条线段, 理想刚体下重心恰在线上属于临界平衡, 但实物磁力片靠底边磁吸完全立得住, 因此允许 0.15 单位的超出量。悬臂式外挑结构 (重心明显越过支撑边) 仍会被正确拒绝。

## 3. 报告格式

每条问题包含: 严重级别 (Error / Warning)、稳定的机器可读 `code`、中文 `message` (含上下文前缀, 如"第 5 步完成后")、涉及的磁力片 `id` 列表。CLI 示例:

```
[错误] 第 5 步完成后: 磁力片 w2_s_1 悬空: 不存在通往地面的支撑路径 (floating_tile)
```

## 4. 与教程一致性检查的分工

物理规则之外, `TutorialEngine::checkConsistency` 负责纯数据层面的质检 (步骤序号连续、每片恰好放置一次、引用存在、说明非空)。`magtile_app validate` 同时执行两类检查, 全部通过才判定"可发布"。

## 5. 规则演进路线 (基础版 → 进阶版)

当前实现刻意保持"基础但严格可靠", 后续按内容库需要演进:

1. **逐片力矩分析**: 对每个磁吸接头估算可承受力矩 (磁力 × 力臂), 拒绝"物理上连通但磁力撑不住"的大悬挑, 替代现在的全局重心近似。
2. **非共面穿插检测**: 多边形对的 3D 相交测试, 覆盖斜插穿模。
3. **子结构稳定性**: 对每个连通子结构独立做重心检查 (当前对整体做)。
4. **搭建顺序人因校验**: 检查每步新增片是否"够得着" (不被已有结构包死)、单手可放置。
5. **柔性接头模拟**: 磁吸片受压时的微小转动, 用于球面/穹顶类高难模型的可搭性预判。
