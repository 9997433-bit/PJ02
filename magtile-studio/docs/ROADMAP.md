# 产品路线图: 通往 500+ 模型内容库

本路线图描述 MagTile Studio 从当前工程地基发展为拥有 500+ 教程模型的商业产品的分阶段计划。每个阶段都有明确的**交付物**与**验收标准**, 内容规模与工程能力交替推进: 先把内容管线打磨到"低成本量产", 再放量生产模型。

## 阶段 0: 工程地基 ✅ (当前仓库)

**交付物**

- C++20 / CMake 跨平台工程骨架, 模块化架构 (core / physics / tutorial / render / app)。
- 9 种标准磁力片形状目录 (数据驱动, `data/tile_catalog.json`)。
- 完整核心数据模型: `TileType`、`TileInstance`、`BuildStep`、`ModelDefinition`。
- 物理校验器基础版: 接地支撑 / 磁力吸合 / 无重叠 / 重心稳定, 覆盖教程全部中间步骤。
- 分步教程引擎 (导航、场景查询、一致性质检) 与渲染接口 (`IRenderer` + NullRenderer)。
- 示例模型「城堡地基与城墙」(72 片 / 16 步) + 程序化生成脚本, CI 级 `ctest` 质检。

**验收标准**: 三平台可编译; `magtile_app validate` 对示例模型全绿。✅

## 阶段 1: 看得见的教程 (渲染与交互 MVP)

**目标**: 把教程从终端搬进 3D 窗口, 形成第一个可演示版本。

- GLFW + OpenGL 4.1 渲染后端 (半透明磁力片、教程高亮描边、新增片放置动画)。
- 轨道相机 (旋转 / 缩放 / 平移), 步骤前进/后退快捷键。
- 磁吸点可视化: 当前步骤新增片与参照片的吸合边闪烁提示。
- 内容扩充至 **20 个模型** (入门难度 1~2 为主: 小房子、花朵、球、火箭), 全部通过质检。

**验收标准**: 非开发人员可用鼠标完整跟完 20 个教程; 帧率 ≥ 60fps @ 1080p。

## 阶段 2: 内容量产管线 (100 模型)

**目标**: 把"做一个模型"的成本从工程师半天降到内容设计师半小时。

- **可视化模型编辑器** (复用核心库): 网格吸附摆放、自动磁力边检测、实时物理校验红线提示。
- 步骤自动划分辅助: 按结构层次 (地台 → 墙体 → 装饰) 建议步骤分组, 设计师微调。
- 程序化生成器扩展为参数化模板库 (塔楼、围墙、屋顶、球体等常用子结构一键生成)。
- 内容规范手册: 难度定级标准、步骤粒度标准 (每步 ≤ 8 片)、文案风格指南。
- 内容库达到 **100 个模型**, 按主题分系列 (城堡 / 交通工具 / 动物 / 几何艺术 / 节日)。

**验收标准**: 新模型从设计到入库 ≤ 0.5 人日; 质检自动化率 100%。

## 阶段 3: 产品化与商业化 (250 模型)

**目标**: 面向付费用户的完整产品体验。

- 用户系统: 本地进度存档、收藏、搭建历史、成就徽章。
- 内容分发: 模型库按系列打包, 支持增量更新与内购解锁 (免费 30 模型 + 订阅全库)。
- 教学增强: 语音朗读步骤 (TTS)、错误常见问答、"我拥有的磁力片"筛选 (按用户套装存量推荐可搭模型)。
- 多语言框架落地 (简体中文首发, 预留繁中/英文)。
- Windows / macOS 安装包与自动更新; Linux 维持开发者构建。
- 内容库达到 **250 个模型**, 难度 1~4 全覆盖。

**验收标准**: 完成付费闭环; 崩溃率 < 0.1%; 内容更新无需发版。

## 阶段 4: 规模化与生态 (500+ 模型)

**目标**: 内容规模突破 500, 建立护城河。

- 物理校验进阶版: 逐接头力矩分析、子结构稳定性、搭建顺序人因校验 (见 PHYSICS_RULES.md 第 5 节), 支撑难度 5 的大师级模型 (摩天轮、多层建筑群、大跨度桥梁)。
- 创作者生态: 编辑器面向高级用户开放, UGC 模型经自动质检 + 人工审核进入社区库。
- AI 辅助设计探索: 从目标轮廓自动生成合法磁力片结构与教程步骤草稿。
- 移动端评估: 核心库本就无 UI 依赖, 评估 iOS/Android 移植 (渲染层换 Metal/GLES)。
- 内容库达到 **500+ 模型**, 其中官方 400+, 精选 UGC 100+。

**验收标准**: 月活跃搭建教程完成数、订阅续费率达到商业目标; UGC 周投稿量稳定。

## 风险与对策

- **内容产能不足**: 优先投入编辑器与参数化模板 (阶段 2 提前于商业化), 用工具而非人力堆量。
- **高难模型"教程可行性"存疑**: 物理校验器逐阶段加严; 难度 4+ 模型入库前增加实物搭建复核流程。
- **渲染技术演进**: `IRenderer` 接口已隔离后端, Vulkan/Metal 迁移不影响内容资产与核心代码。
- **套装差异 (不同品牌尺寸/配件)**: 形状目录数据驱动 + `unit_mm` 标定, 支持按品牌加载不同目录。
