## 0. 使用方法 (验收人开工前读一遍)

1. **构建机先行**: 在 macOS 构建机跑 `bash scripts/smoke_qt_macos.sh`
   到零 SKIP 全绿 (末行 `N 项通过, 0 项失败, 0 项跳过`; 带 SKIP 的
   `PARTIAL` **不满足**), 完成 §1.2 前置勾选并登记 DMG 产物;
2. **干净机器**: 未装 Qt / Xcode 的 macOS 12+ 物理机或虚拟机 (VM 须
   开 3D 加速, 否则教程视口空白误报); Apple Silicon 与 Intel 至少各
   验一台为佳, 至少一台并在 §1.1 登记芯片架构;
3. **顺序执行**: 按 §2 → §8 逐项操作, **当场**勾选与记备注; 任一
   P0 项不通过 → 停止勾选, 记入 §9 失败登记表, 按手册 12.4 排查表
   定位后修复重验 (本单不重复排查表内容);
4. **签名档位分流**: 内测 ad-hoc 档只验 §7 中标注 `[ad-hoc 也验]`
   的项 (其余记 N/A), 结论最高只能记「内测通过」; **D4 收口必须以
   Developer ID 正式档跑完 §7 全部项**;
5. **严禁未实测勾选或事后补签** —— 伪造验收结论比不验收更危险。
