## 2. 口径与归类方法

`data/model_catalog.json` 的 `theme` 字段是**展示用主题角标** (由标签推导, 如「城市生活」「自然世界」「游乐园」), 与策略 2.2 节的 13 个排期主题**不是同一套词表**; 全库 250 个模型的 `content_meta.series` 字段 (schema v2 中承载策略主题的正字段) **仍然全部缺失** (上一版建议的回填未执行)。因此本审计继续按模型 id / 名称 / 标签 / 描述逐一人工归入 13 主题, 归类判例沿用上一版:

1. **就近归入, 但不硬塞**: 与某主题定位 (2.2 节右列) 明确同族的才归入; 城市生活/职业体验/运动/田园农事等确无归属的, 记入「矩阵外」桶, 不摊薄矩阵内数字。
2. **载具基础设施跟随载具主题**: 机场航站楼/塔台/机库/港口/船坞/灯塔 → 海空交通; 车站/道口/停车场/加油站 → 陆地交通 (工程机械亦按策略原文归陆地交通)。
3. **策略文档自带判例优先**: 2.2/§6 节点名的归属直接沿用——`rescue_hq_01`/`roman_aqueduct_01` → 建筑地标 (§6 ⑪⑧), `trex_skeleton_01` → 动物世界 (§6 ②), 摩天轮/风车/机甲 → 幻想与机械 (2.2 节原文), 测地穹顶 → 几何艺术 (§6 ⑤)。
4. **动物场馆归动物世界**: 动物园馆舍/观兽设施 (企鹅池、大象馆、观鲸站) 与具象动物同归, 因其造型主角是动物。
5. **民俗节庆归节日限定**: 龙舟 (端午)、舞狮 (新春)、雪人 (冬季亲子) 按节庆属性归入, 不按"船/人偶"拆散。

**本轮复核结果**: 234 基线的全部归类经逐条对质后维持不变 (250 目录中 234 个旧 id 全部在库、难度零变动)。批 F–I 新增 16 个的归类裁定 (争议点逐一说明):

## 6. 矩阵外 74 个: 定性与治理建议 (升级为决断项)

矩阵外模型按目录展示主题聚类: 城市生活 24 (+1 回收站)、运动 11、田园 8 (+1 蒙古包)、工程结构 6、音乐 5 (+1 管风琴)、自然世界 4、校园 4、游乐园 3 (+2 马戏团/秋千, 原滑梯乐园并入)、海洋航行 3、博物馆 2、其他 4 (极地/航天探索/夏日乐园/足球 各 1)。

这批内容依旧**不是废品**——城市生活/职业体验是免费 30 的主力供给, 游乐园/运动自带亲子话题性; 批 F–I 的 5 个矩阵外新增也全部通过唯一性与反幼稚检查, 单品质量无可指摘。问题仍是策略与产线两张皮: 上一版摆出的两条治理路线 (**修订矩阵** 承认既成事实重分 520 总盘 / **冻结矩阵外供给** 选题池只从 13 主题出题) **至今没有决断**, 于是本轮 31% 的产能 (5/16) 继续流向不消耗任何矩阵格子的选题。

本轮升级建议: 把这个决断列为**批 J 开工前的阻塞项**——按当前节奏每 16 个新增漏 5 个, 到 400 库时矩阵外将累计 ~120 个, 届时无论选哪条路线, 重分/回填的成本都翻倍。无论选哪条, 都应**立即回填全库 `content_meta.series` 字段** (13 主题词表 + 增设主题; 当前 0/250), 让本审计从人工归类变成 `update_model_catalog.py` 可机检的常规指标。附录 A 的归类清单可直接作为回填底稿。
