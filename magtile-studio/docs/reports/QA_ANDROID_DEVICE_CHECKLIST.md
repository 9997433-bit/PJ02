## 2. P0 人工项 (M-01~M-05, 任一 ❌ 阻断上架)

进入方式: 模型库勾「只看免费」→ 任选一张免费卡 → 「🧲 开始搭建」。

| # | 验证点 | 步骤与期望 | 状态 | 备注 |
| --- | --- | --- | --- | --- |
| M-01 | 3D 渲染正确性 | 教程页顶部视口: 地面网格 + 半透明彩色薄板与桌面 Qt 视口同观感 (同一份 GlSceneRenderer); 当前步新增片橙色描边、之后未放片为淡化 ghost 轮廓、参照片琥珀描边; 逐步翻页画面随步更新; **留真机截图对照桌面** | ⬜ |  |
| M-02 | 触屏手势手感 | 单指拖动旋转 (0.32°/dp, 跟手不漂); 双指捏合缩放 (12%/格对数曲线, 与桌面滚轮同感受); 双指同向滑动平移; 第二指落下/抬起瞬间画面不跳变; 三指取前两指不乱 | ⬜ |  |
| M-03 | 呼吸动画 | 常规档: 当前步新增片橙色描边以 1.2Hz 正弦明暗呼吸, 不卡顿; 开发者选项关闭系统动画后杀进程重启: 描边定格最亮帧恒定不闪, 手势/翻步仍即时重绘 (脏帧模式) | ⬜ |  |
| M-04 | 断点续搭 | 走若干步 → 返回键退出 → 从详情弹窗重进: 停在离开的下一步, 视口同步; Home 切走再回 / 锁屏恢复: 画面恢复 (GL 上下文重建), 进度不丢。数据链路已由 §1-2 自动覆盖, 此处补人眼确认视口与步骤列表定位一致 | ⬜ |  |
| M-05 | 完成链路 | 走完全程: 末步按钮「完成 🎉」→ 完成横幅 + 进度头变完成文案 + 视口停在末步全貌; 退出后进度页「已完成」列表出现该作品 (完成日期/用时/片数), 成就墙首搭徽章 🏗️ 点亮; 「再搭一次」从第 1 步开始且首次完成日期不变 | ⬜ |  |
